# NICOLY CRM 操作マニュアル（オーナー・管理者向け）

Phase 3（お金: 単価・請求・支払い・月次締め・書き出し）時点の内容です。お金の画面と金額はオーナーだけが見られます（管理者には出ません）。

---

## 1. はじめに

### ログイン

- アプリの URL を開き、**「Google でログイン」**（招待されたメールアドレスの Google アカウント）を押します。
- Google アカウントがない場合は、メールアドレスを入れて**「ログイン用のリンクを受け取る」**→ 届いたメールのリンクを押します。
- ホーム画面に追加すると、アプリのように開けます（iPhone: 共有ボタン →「ホーム画面に追加」/ Android: メニュー →「ホーム画面に追加」）。

### 画面の見方

| | スマホ | PC |
|---|---|---|
| メニュー | 下のタブ「ホーム / 現場 / スタッフ / 営業 / その他」 | 左のメニュー |
| 現場を作る・活動を記録 | ホーム・現場一覧・営業の右下の ＋ →「現場を作る」/「活動を記録」（オーナーは「経費を入れる」も） | 現場一覧の「＋ 現場を作る」、会社の画面の「記録する」 |
| 検索 | 上の検索窓（名前・会社・会場・電話番号。ひらがな / カタカナ、ハイフンの有無はどちらでも可）。結果の画面では探した言葉が残るので、そのまま直して探し直せます | 同じ |

**色の意味**: 赤 = 要対応（欠員・未報告・キャンセルなど）、黄 = 待ち（打診中・未提出など）、緑 = 完了。会場名の前の丸は**会場の色**です（稼働表・ホーム・現場一覧・カレンダーで同じ色）。

**見た目**: 色は濃く塗りつぶさず、薄い地にはっきりした線や札で知らせます（赤い「欠2」の札、左の赤い線など）。稼働表のマスだけは、遠目でも分かるようにしっかり塗ります（会場の色 = 埋まった、赤 = 足りない、白 = 何もない）。ボタンは押すと少し沈みます。「現場」の**カレンダー**では、欠員のある日がマスごと薄い赤に赤い「欠2」の札、そろった日が薄い緑に緑の「✓」、過ぎた日は灰色、今日は青い枠で、小さな丸はその日の会場の色です（見方は表の上に出ています）。PC の左のメニューは「毎日の作業 / 管理 / 設定・記録」に分かれています（スマホの「その他」も同じ）。実績確認・交通費の承認・稼働可能日の未提出の**残りの数**が、PC は左のメニュー、スマホは「その他」の右に札で出ます（黄 = 残りあり、赤 = 締切を過ぎた。スマホは下の「その他」に黄色の点）。現場一覧・ホームの人数も稼働表と同じ札（「2/4人」と赤い「欠2」、そろったら緑の「✓」、黄の「打1」= 打診中）です。

**オーナーと管理者の違い**: 管理者には金額（日当・単価・口座など）が一切表示されません。設定・データ取り込み・変更履歴・会社の経費はオーナーだけが使えます。

## 2. 毎日の流れ

### ① ホームで「要対応」を見る

いちばん上の **「埋まり具合」** に、明日と明日から7日間の人員がどれだけ埋まったかがゲージで出ます（今日の分はもう決まっているので出しません）（青 = 埋まった人数。全部そろうと緑に変わり「✓ 全部うまりました！」。足りない人数は「あと〇人で全部うまる」の赤い数字）。

スマホでは、そのさらに上に **「LINE の文を貼るだけ」** の箱があります（Phase 18）。LINE に来た文（件数の報告・稼働可能日・募集の文・案件詳細・打診の返事）を長押しでコピーして貼り、「読み取る」を押すと、何の文かを見分けて確認カードを出します。「登録する」で入ります（→ 2-4）。

その下に、やるべきことがまとめて出ます（「要対応」の横の赤い丸は件数）。押すとその画面に移ります。会場名の前の丸は、会場の色です。

- **7日以内で欠員のある現場** → 押すと「候補を探す」が開きます
- **未回答の打診**（24時間以上たったものは赤）→ LINE で返事が来たら、その行の **「確定」「辞退」** を押すだけ（画面の下に出る「元に戻す」で戻せます）
- **明日の現場で前日リマインドを送っていない**
- **実績の未報告**（稼働日を過ぎてもスタッフが報告していない）→ 押すと、その現場の実績確認が開きます。LINE に来た報告は「LINE の文を貼るだけ」に貼るのが早いです
- **未承認の交通費・経費**
- **翌月分の稼働可能日の未提出**（締切を過ぎると赤）
- **シートの名前が CRM と合わないもの**（オーナーだけ。シートを自動で読んでいるとき → ②-4）
- **案件で自分の番**（本人への確認・スキルシート・候補日の送付・現場詳細。24時間以上たつと赤）→ 押すと案件の一覧が開きます（→ ②-5）

その下の **「今日やること（営業）」** には、次回アクション日が今日以前の取引先・協力会社が出ます（過ぎたものは赤）。電話したら、その行の「記録」から記録します（→ ⑨）。

### ② 現場を作る

- **1日だけ**: ＋ →「現場を作る」→ 取引先・会場・日付（「今日 / 明日 / 来週の今日」をワンタップでも）・時間・役割ごとの必要人数 →「現場を作る」（スマホではこのボタンが画面の下に出ています）
- **まとめて**: 現場一覧 →「まとめて作る」→「来週の土日」などを押す（期間と曜日も選べます）→ 作らない日はタップで外す →「○件の現場を作る」
  - まとめて作った現場は「グループ」になり、グループごとに一覧できます。
- **募集の文から**: 現場一覧 →「募集の文から作る」（スマホは ＋ →「募集の文から作る」）→ 取引先の LINE の募集の文を長押しでコピーして貼る
  - 日付（「11/1・5・6・10」のように並んだもの、「10/12(月/祝)」など）・会場（「■稼働場所」「▼〇〇」）・時間（「11時〜19時」「10:30-18:30」）・役割と人数（「クローザー：各日1名」「募集：クローザー1名」）を読み取ります。集合は開始の30分前にしておきます
  - 「読み取った内容」で ✓ が付いたものが読めたもの。読めなかったものは下の入力欄で入れてください
  - 優遇日（「〈優遇日〉」の下の日）は日付に ★ が付きます（作る現場は募集日の全部です）
  - 会場が CRM になければ「この名前で会場を作る」で作れます（住所などはあとで会場の画面で）
  - 取引先は文からは分からないので選んでください。作らない日はタップで外し、「○件の現場を作る」
  - 単価などの金額は読みません
- **別の日にコピー**: 現場の詳細 →「複製」→ 日付を選ぶ
- 服装・持ち物・注意事項・集合場所は「詳細」を開いて入れます（スタッフへの文面に入ります）。

### ②-2 稼働表で月全体を見る（今のシートと同じ形）

下のメニューの **「現場」** を押すと、まず稼働表が開きます。上の切り替えは「稼働表 / リスト / カレンダー」の順です。PC は右上の「＋ 現場を作る」、スマホは右下の ＋ から現場を作れます。

「現場」→ 上の切り替えで**「稼働表」**。今の月のスプレッドシートと同じ並びで、月全体を見渡せます。

- **会場ごとの色**: 会場には色が1つずつ付いています（青・紺・水色・紫・藤・桃・茶）。上の段の現場と下の段のスタッフのマスが同じ色になるので、**誰がどの会場へ行くか**が一目で分かります。色は「会場」の画面の「編集」で変えられます（新しい会場には、使っている会場が少ない色が自動で付きます）
- 表の上の **「埋まり具合」** のゲージに、今日から月末までの人員がどれだけ埋まったかが出ます
- **リストと表**: スマホは最初に**日ごとのリスト**、PC は**表**が出ます。右上の「リスト / 表」で切りかえられます（端末に覚えます）
  - リスト: 今日から1日ずつ、**欠員の現場が上**に並びます（足りない現場は赤、そろった現場は会場の色で塗ってあります）。現場を押すと現場の画面へ。欠員のある日は「この日○で空いている人」を開いて名前を押すと、表のマスと同じ画面（稼働可能日・打診・確定）が開きます。現場のない日が続くところは1行にまとめます。過ぎた日は「過ぎた日も見る」で出ます
- **絞り込み**（表の上のボタン。押すと青くなり、もう一度押すと戻ります。端末に覚えます）
  - **欠員の現場だけ**（数字は欠員の現場の数）: そろった現場・中止の現場と、欠員のない取引先の行を隠します
  - **○で空いている人だけ**（数字は人数）: ○を出していて、その日まだ予定のない人（＝いま打診できる人）だけを下の段に出します
  - **今日から**: 過ぎた日を隠し、今日の列から始めます（今の月のときだけ）
- **人数分のマス**: 現場の「確定/必要人数」を、1人 = 1マスで見せます。**確定は塗り**、**打診中は縞**（回答待ち）、空きは枠だけ（塗ったマスの上なので、白か濃い紺で描きます）。0/2 は空、1/2 は半分、2/2 でマスが会場の色になり ✓ が付きます。9人以上の現場は1本のバーです
  - 日付の下の細いバーはその日全体、取引先名の下のバーと数字（例: 6/8）はその取引先の月の埋まり具合です
  - 欠員の現場の緑の **「○25」** は、その日○で空いている人の数です（打診できる人がいるかの目安）
- **色の見方（2026-10 に分かりやすくしました）**: マスはしっかり塗ってあります。**会場の色 = 埋まった現場・その人の確定の予定**、**赤 = 足りない（欠員）・キャンセル**、**黄 = 返事待ち（打診中）**、**白 = 何もない**。遠目で「赤いマスがある日 = 手を打つ日」です
- **つながりを光らせる**: マスを押す（PC はマウスを乗せるだけでも）と、**同じ現場のマスが青い枠で光り**（上の段の現場と、下の段でその現場に入る人）、**同じ会場のマスは点線**、ほかは薄くなります。その行の名前と日付の見出しにも色が付きます。**足りない現場を押すと、その日○で空いている人が緑の枠で光る**ので、だれに打診すればいいかがすぐ分かります。もう一度押す・Esc・「光らせるのをやめる」で戻ります
  - 表の上の**会場のボタン**（現場の多い順。多いときは「ほか○か所」）を押すと、その会場のマスだけが光ります（同じ会場の現場が月のどこにあるか）
  - **「次の欠員へ」**（表の上の赤いボタン。数字は足りない現場の数）を押すと、足りない現場へ順に飛んで一度大きくなり、つながりが光ります
  - 足りないマスは静かに脈打ちます。確定などで新しく入ったマスは「ポン」と出ます（端末の「動きを減らす」設定ではどちらも止まります）
- **上の段（現場）**: 取引先ごとに、その日の会場。**人が足りない現場は赤く塗って**白い「欠2」の札（2人足りない）と会場の色の丸、埋まっている現場は**会場の色で塗って**白い「✓」。黄色の「打1」は打診中の人数。点線で「中止」は中止の現場
  - 1つのマスに出す現場は1件で、欠員の現場が先に出ます。ほかにもあるときは「＋1件」（隠れた現場に欠員があれば赤で「＋1件（欠1）」）。マスを押すとその日の現場が全部出ます（行が高くなりすぎないようにするため）
  - いちばん上の「欠員（その日）」の行は、欠員のある日は**マスごと赤**で、その日の欠員の合計が白い札で出ます（足りている日は緑の ✓）。日付の見出しにも「欠3」の赤い札が出るので、下へ動かしても分かります
  - 今日の日付は青い丸で、列はうすい青。土日・祝日の列はうすい灰色で、日付の文字が土曜は青、日曜・祝日は赤です
  - マスを押すと、その現場の詳細が開きます。空いたマスを押すと、その日・その取引先で「現場を作る」が開きます
- **下の段（スタッフ）**: ランク順に、その日の予定。**会場の色で塗ったマス = 確定**、**黄色に「打」（左の太い線が会場の色）= 打診中**、灰色に「補」= 補欠、**赤に「✕ キャンセル」「✕ 当日不稼働」= 確定していたのに来られなくなった**、丸い地の ○（緑）△（黄）×（灰）= 稼働可能日。右端は確定した稼働日数
- 表の上の数字（オーナーだけ）は、その月の売上・支払・粗利。押すと「お金」の画面が開きます。キーボード・マウスでの操作は「キーボード・マウスでの操作」を押すと出ます（PC）
  - 確定して現場の欠員がなくなると「この現場は全員そろいました！」と出ます
- 表の下に、色と印の見本（凡例）があります
- スタッフのマスを押すと:
  - **稼働可能日**の代理入力（○・△・×・未入力）
  - **その日の現場**への「打診する（LINE）」「確定にする」。×の日・同じ日に別の現場・会場/取引先NG・役割が埋まっているときは赤い注意が出ます
  - 押したあとに出る「元に戻す」で取り消せます
- 名前の列と日付の行は固定です。表の中を指で上下左右に動かせます
- **拡大・縮小**（スプレッドシートと同じ感覚で、表の中だけ大きさが変わります）
  - スマホ: 表の中を **2本指でつまむ / 広げる**（画面全体は拡大されません）
  - PC: **Ctrl（Mac は ⌘ でも可）を押しながらマウスのホイール**、またはトラックパッドでつまむ
  - 表の上の **− / ＋** でも変えられます（25%〜200%）。真ん中の「100%」などの数字を押すと元の大きさに戻ります
  - 倍率はその端末に覚えておくので、次に開いたときも同じ大きさです
- **全画面**: 表の上の「全画面」を押すと、画面いっぱいに表だけが出ます（ページの上に表を重ねて出す形）。「閉じる」（PC は Esc キーでも可）で元の画面に戻ります。全画面のままマスを押して打診・確定もできます
- **スプレッドシートと同じ操作**（主に PC）
  - マスを押すと、そのマスに青い枠が付き、**その行と列に色が付きます**（日付と名前の見出しも太字になります）
  - **矢印キー**で移動、**Shift＋矢印**か**マウスでドラッグ**で範囲を選べます（Ctrl＋矢印で端まで、Ctrl＋A で全体）。**Enter** でマスを開きます（押したときと同じ画面）
  - **Ctrl＋C**（Mac は ⌘＋C）で選んだ範囲をコピーし、ほかのスプレッドシートや LINE に貼り付けられます（PC は表の上の「コピー」でも可）。金額は入りません
  - スタッフのマスで **1 = ○、2 = △、3 = ×**（o・x でも可）を押すと、その日の稼働可能日がすぐ入り、次の日に進みます。範囲を選んでから押すとまとめて入ります。**Delete**（Backspace）で消します。画面の上に出る「元に戻す」で取り消せます
  - Esc で選択を外します（全画面のときは、もう一度 Esc で閉じます）
- **列の幅・行の高さ**
  - 見出しの右端（日付・「日付」の列）を**ドラッグ**すると、日付の列（まとめて）・名前の列の幅を変えられます。ダブルクリックで元の幅に戻ります
  - 表の上の「行の高さ」ボタン（中 → 小 → 大）で行を詰めたり広げたりできます。小にすると最寄り駅を隠して、会場名を1行にします
  - 幅・高さはその端末に覚えておきます
- 「前の月」「次の月」で月を変えられます

- **単価（オーナーのみ）**: 稼働表のマスに、現場の人日単価（例: ¥22,000。役割で違うときは ¥20,000〜25,000）と、スタッフの日当が小さく出ます（今のシートの「単価」の行と同じ情報）。行の高さを「小」にすると隠れます。管理者には出ません

### ②-3 見るだけリンク・シートへの書き出し（現場リーダー・スタッフへの共有）

稼働表の右上のボタンから使います。どちらも**金額・電話番号・打診中の情報は出ません**。

- **見るだけリンク**: ログインなしで稼働表を見られるリンクです。「LINEで送る」「コピー」で現場リーダー・スタッフに送ります。見るだけリンクの画面でも、2本指・− / ＋・全画面で拡大・縮小できます
  - 見るだけリンクの画面でも、マスを押すと**同じ現場・同じ会場のマスが光り**、足りない現場は赤く点滅します。「会場」「次の欠員へ」のボタンも使えます（②-2 の「つながりを光らせる」と同じ）
  - 作る・止める・作り直すのはオーナーだけ。作り直すと古いリンクはすぐ使えなくなります（リンクが漏れたときに）
  - 見られるのは先月〜3か月先です
- **シートへの書き出し**: 稼働表（今月と来月）を、スプレッドシートの **「CRM 202610」「CRM 202611」のような CRM 専用のタブ**に**10分ごと**に自動で書き出します。見るだけ用です（シートで直しても CRM には戻りません）
  - 並びは今のシートと同じです（取引先・会場ごとに「単価 / 現場 / 人数」、スタッフごとに「単価 / 場所 / シフト」の3行）。ただし**単価の行は空**です（共有するシートに金額は出しません）
  - 最初にオーナーが書き出し先のスプレッドシートの URL を入れます（準備は setup.md ⑨）
  - **いつもの管理用シートを書き出し先にしても大丈夫です**。CRM は「CRM 〜」のタブにしか書かず、手で作った「202610」などのタブには触りません。同じ名前の「CRM 〜」タブを人が作っていたときは、上書きせずに止まります
  - 「今すぐ書き出す」で、すぐに最新にできます。最後に書き出した時刻と結果が出ます

### ②-4 シートを自動で読む（いつものシートが正。Phase 18）

いつもの管理用スプレッドシートに書いていれば、CRM にもう一度入れなくてよい仕組みです。**「その他 → データ取り込み」のいちばん上「シートを自動で読む」**（オーナーだけ）。

- **読む元の URL** に管理用シートの URL を貼ります（空なら「シートへの書き出し」の書き出し先と同じシートを読みます）。**人数を入れる役割**（シートには役割がないので、人数をどの役割に入れるか）を選び、**「自動で読む（10分ごと）」**をオンにします。「今すぐ読む」で、すぐに試せます
- 読むのは**今月と来月のタブ**（「202611」のような名前）。上の段（単価 / 現場 / 人数）から現場・必要人数・請求単価、下の段（単価 / 場所 / シフト）から確定した予定・日当・○△× を入れます（月の稼働表の取り込みと同じ読み方）。シフトの印は ⭕️（出せる）→ ○、🔺（入りそうだが空くかも）→ △、❌ → ×、**⭐️（確定）→ ○**（確定した予定そのものは「場所」の会場名から入ります）。空白はそのままです
- **シートに書けば10分以内に CRM に入り、シートから消せば CRM からも外れます**。ただし、今日より前の分・報告や実績が入っている分・CRM だけで入れたもの（打診中など）は外しません。外さなかったものは結果の「くわしく」に出ます
- **名簿にない人・ない会場・取引先は自動では作りません**。「シートの名前が CRM と合わないもの」に出るので、どれのことか（または「新しく作る」「取り込まない」）を決めてください。決めたことは覚えて、次に読むときから自動で入ります。ホームにも件数が出ます
  - 名字だけ・ふりがな・LINE の表示名が同じ人、「株式会社」の違いだけの取引先、「DS」の有無や店名の一部が同じ会場、下の段にだけある場所（研修など）はその会場でいちばん多い取引先 を **「候補」として先に選んであります**（理由つき）。合っていれば「候補どおりにまとめて決める」を1回押すだけです。違うときは選び直してください。同じ名字の人が2人以上いるときは候補を出しません（自動で決めることはありません）。月の稼働表の手の取り込み（下の「月の稼働表」）でも同じ候補が先に選ばれます
- 本人がマイページで出した○△×は、シートで上書きしません
- Google の設定（setup.md ⑨）がなくても、シートが「リンクを知っている全員」が見られる共有なら、URL だけで読めます。共有を絞っている場合は ⑨ の設定をしてください（読むだけなら「閲覧者」で足ります）
- 稼働表の上に「シートから読んだ: 10/22 12:10」のように出ます（赤いときは読めなかったか、合わない名前があります）
- **CRM で入れたものをシートにも書く（書き戻し。Phase 19）**: 同じ画面の「シートにも書く（2分ごと）」をオンにすると、CRM で確定・辞退・現場を作る・人数を直す・○△×を入れたときに、いつものタブの同じマス（スタッフの「場所」「シフト」、取引先の「現場」「人数」）にも2分以内に書きます。マイページから本人が入れた○△×や「参加できる」も同じです
  - Google の設定（setup.md ⑨ のサービスアカウント。シートに「編集者」で共有）が必要です。読むだけ（上の自動の読み取り）と違って、これがないと書けません
  - 単価の行は書きません。シートにその人・取引先の行がないときは、**「シートに行がない人・取引先は、行を足す」**をオンにしていればその段のいちばん下に3行の組（単価 / 場所 / シフト、単価 / 現場 / 人数）を足してから書きます。見た目と右側の計算式（出勤日数など）はすぐ上の組を写し、単価の行と日付のマスは空のままです。オフなら「書けなかった」として一覧に出るので、シートに行を足してください（次から書けます）
  - 名字だけなど、その人・取引先かもしれない行がもうあるときは足しません（二重の行を作らないため）。「書けなかった」に理由が出るので、上の「シートの名前が CRM と合わないもの」でその行がだれのことか決めてください（決めればその行に書きます）
  - シートの書き方が CRM の会場と合わないマス（合わない名前）は消したり上書きしたりしません。CRM で○△×を消しても、シートの印は消しません（消すのはシートで）
  - **⭐️（確定）**: CRM で確定にすると、「場所」に会場名を書くのと一緒に、シフトのマスに ⭐️ を書きます（空欄か ○△× のときだけ。読めない印は触りません）。確定が外れる（辞退・キャンセル）と ⭐️ は ⭕️ に戻します。○△× の書き戻しで ⭐️ を上書きすることはありません
  - 「今すぐ書く」で、待っているマスをすぐに書けます。最近書いたもの・書けなかった理由は同じ画面に出ます

### ②-5 案件の進み具合（スキルシート → 面談 → 合否 → 現場詳細。Phase 21）

取引先から案件の文が来てから人が決まるまでを、**「その他 → 案件」**（PC は左のメニュー）で一か所に見ます。

- **案件を作る**: 取引先の LINE の案件の文をコピーして「案件を作る（文を貼る）」に貼ります。書き方は取引先ごとに違いますが、**要素に分けて読みます**: 全体の日程（「■ 日程 1/1〜1/4」）・エントリー期限（「■ エントリー期限 11/20まで」）・店舗（「① 〇〇店」「・〇〇店 →25名」「20 〇〇外販 1名」）・店舗ごとの日程（店舗の下の「【日程】1/2・1/3・1/4」）・人数（「→25名」「各日1名」）・単価の行（「弱 30,000円」「一律 24,000円」）・稼働時間・備考（※ の行や条件）。読んだ内容は **「店舗と日程」の表** に出るので、店舗ごとの日程（空なら全体の日程を使います）と人数を直し、足りない店舗は「店舗を足す」で足せます。「できる現場 N件を見る」で、日 × 店舗 に展開した現場を確かめられます。会場は近い名前が候補として先に選ばれます（ない会場は「この名前で新しく作る」）。取引先を選んで「案件と現場を作る」。現場（1日×1会場）がまとめてでき、必要人数も入ります。単価はオーナーだけが入れられ、現場の請求単価にも入ります。文の中の金額の行は「単価のメモ」（オーナーだけ）に入り、備考には入りません（貼った文も単価が入っているのでオーナーだけが見られます）。エントリー期限は案件のカードと画面に出ます（過ぎると赤、3日前から黄）。「①初期設定ヘルパー / 店舗：〇〇 / 日程：3.26日 / 単価：20,000円」のように役割ごとに段落が分かれた文も読めます（「3.26日」は 3日と26日。役割は店舗の名札になって現場の備考に入り、段落の単価はその現場の請求単価になります。オーナーは表の「単価」で直せます）。ホームの「LINE の文を貼るだけ」に貼っても、この画面に進めます
- **候補を足す**: 案件の画面で名簿から選びます。候補の人は **候補 → 本人OK → スキルシート提出済 → 候補日あり → 候補日送付済 → 面談日時共有済 → 面談済 → 合格／不合格 → 現場詳細展開済** と進めます（「次へ」を押すだけ。候補日時・面談の日時はそのとき入れます）。間違えたら知らせの「元に戻す」
- **日程に入れる**: 候補の人をこの案件の日程に打診中として入れておくと、**合格を押したときにまとめて確定**になります（確定連絡の文は現場の画面から。シートの書き戻しも今までどおり）。不合格・辞退にすると打診中の予定は辞退になります
- **LINE に貼る文**: スキルシート提出済のときは「面談の候補日時のお願いの文」（本人へ）、候補日時がそろったら「取引先へのまとめ文」（会場・日付・名前・候補日時の順）、面談の日時を入れたら「面談の日時の共有の文」（本人へ）をコピーできます。金額は入りません
- **だれの番か**: 札の色で分かります。赤＝自分の番で24時間以上たっている、黄＝自分の番・本人や取引先の返事待ち、緑＝合格。ホームの「要対応」にも「案件で自分の番 N人」と出ます
- **カンバン**: 一覧の「カンバン」で、列＝段階に人の札が並びます。PC では札をほかの列に動かすと段階が変わります（元に戻せます）
- **貼った文からも進められます**（ホームや「LINE から入れる」に貼る）: 本人からの面談の候補日時（「10/26 20:00〜」が並ぶ文）→ だれの分か選んで確認カード。取引先からの合否（「〇〇さん合格です」）→ 案件を選んで確認カード（合格なら確定まで）。人員変更（「〇日の△△ ××欠員のため人員変更。□□ Aさん」）→ 現場と人を確かめて確認カード（欠員の人はキャンセル、書いてある人は確定）。登録は確認カードの「登録する」を押したときだけです
- 終わった案件は「終わった案件にする」で一覧から隠せます（「終わった案件も見る」で出ます）

### ③ 候補を探して打診する

1. 現場の詳細 →**「候補を探す」**
2. 打診する役割を選ぶ（欠員のある役割が最初から選ばれています）
3. 候補は **○ → △ → 未提出 → ×・NG・同日に別現場** の順に並びます。同じ順位の中はランク → 平均獲得件数の順です。
   - 赤い印: 同日に別現場 / 会場NG / 取引先NG / 注意（直前キャンセル・遅延などの回数）
   - 緑の「エリア一致」: 会場のエリアに対応できる人
4. 打診する人にチェック →**「打診する」**（NG などの人が入っていると確認が出ます）
5. 文面が1人ずつ出るので、**「LINEで送る」**→ LINE で本人を選んで送信。PC では**「コピー」**して LINE に貼り付けます。

### ④ 回答を待つ

- スタッフがマイページで「参加できる」を押すと、**自動で「確定」**になります（定員に達していたら「補欠」）。
- LINE で口頭の回答が来たときは、**ホームの「未回答の打診」の行の「確定」「辞退」を押す**だけです（1タップ。「元に戻す」で戻せます）。返事の文を「LINE の文を貼るだけ」に貼っても、同じ一覧が出ます。現場の詳細のアサイン一覧で名前の右の「…」→ 状態を選ぶこともできます。
- いつものシートで回している場合は、シートの「場所」のマスに会場名を書けば、10分以内に CRM でも確定になります（→ ②-4）。逆に CRM で確定すれば、書き戻しをオンにしていれば2分以内にシートの「場所」にも入ります。
- 欠員が埋まると、ホームの赤い表示が消えます。

### ⑤ 確定連絡・前日リマインド

- 現場の詳細 →**「確定連絡を送る」**→ 1人ずつ「LINEで送る」。送ると「確定連絡済み」になります。
- 前日（と当日）は**「前日リマインドを送る」**が出ます。送っていない人がいるとホームに出ます。

### ⑥ キャンセル・当日不稼働

- アサイン一覧の「…」→「キャンセル」または「当日不稼働」→ 理由を選ぶ。
- スタッフの**稼働履歴メモに自動で記録**されます（直前キャンセル・遅延などは、候補一覧の「注意」の回数に入ります）。
- 稼働表では、その人のマスが**赤**になり、現場のマスも欠員で赤になります。
- **ほかのオーナー・管理者の画面に、赤いポップアップ「欠員が出ました」が出ます**（今日以降の現場だけ。操作した本人には出ません）。CRM を開いている人には1分以内に、閉じている人には次に開いたときに出ます。「代わりの人を探す」で候補の画面へ進めます。「確認した」を押すと、次からは出ません。
- LINE の「社内に知らせる」をオンにしていると、LINE にも【キャンセル】【当日不稼働】が届きます（→ 2-3）。

### ⑦ 実績を確定する

- スタッフは稼働日の夜〜7日後までに、マイページから件数・コメント・交通費を報告します（＝速報）。
- **「その他 → 実績確認」**: 現場ごとに、速報の件数が最初から入っています。
  - そのままでよければ**「速報どおり確定」**（現場ごとにまとめて）
  - 件数を変えるときは ＋ / − で直し、**差分の理由**（キャンセル / 否認 / 入力ミス / その他）を選んで「確定する」
  - 未報告の人は、LINE などで聞いた件数を入れて「代理で入力して確定」。**LINE に来た報告の文は、ホームの「LINE の文を貼るだけ」に貼ると速報として入ります**（→ 2-4）
  - 確定後も「修正する」で直せます。「履歴」で誰がいつ何から何に変えたかを確認できます。

### ⑦-2 日報を取引先ごとの書式で送る（LINE にコピー）

- **「実績確認」→ 右上の「日報（LINE用）」**: 日付（今日 / 昨日 / ‹ ›）を選ぶと、その日の取引先ごとに、報告の件数・コメントを**取引先の書式の文章**にして出します。「コピー」（スマホは「LINEで送る」も）で取引先の LINE に貼ります。
  - 件数は、確定していれば確定件数、まだなら速報です。報告していない人は「（未報告）」と出るので、集まってからコピーしてください
- **書式を作る・直す（オーナー）**: 「設定 → 日報のフォーマット」
  - 「新しいフォーマットを作る」→ 名前（例: NextWave用）・**使う取引先**（空なら全取引先）を選ぶ
  - 文面は4つの欄に分かれています。**はじめ**（最初に1回）→ **現場ごと**（会場ごとに1回）→ **1人ごと**（その現場の1人ごと）→ **おわり**（最後に1回）
  - 欄を押すと下に `{名前}` `{件数一覧}` `{件数:新規}` などのボタンが出ます。押すとその場所に入ります。右（スマホは下）のプレビューで出来上がりを確かめて「保存する」
  - 「スタッフのマイページにも出す」をオンにすると、スタッフが報告を送ったあと、マイページに同じ書式の「LINE用にコピー」が出ます（ふつうの書式は本人の分だけ。下の「現場の全員分をまとめる書式」は全員分）
  - **見本から作る: NextWave（ネクストウェーブ）**: いただいた報告フォーマット（日付・現場・稼働者・【実績】・【所感】）がそのまま入ります。使う取引先を選んで「このフォーマットを作る」
  - **見本から作る: NICOLY**: NICOLY フォーマット（「10/11 現場名」・稼働者・【実績】の「当日」「後日」の下に「新規1(山田)」の形）が入ります。最初から入っていた仮の「NICOLY用」も、この形に置きかえました（直していなかった場合）
  - 差し込みの意味: `{獲得した項目}` = 獲得した項目だけ1行ずつ（0件は出ない。1つもなければ「なし」）、`{当日・後日の実績}` = 「当日」「後日」に分けて「新規1(山田)」の形で1人ずつ（後日は「〇〇（後日）」の項目）、`{稼働者}` = その現場の全員の名前、`{所感}` = 全員のコメント（2人以上なら名前つき）、`{件数一覧}` = 全部の項目を1行に
  - **稼働開始の報告（任意）**: 現場に着いたときにスタッフが送る文（NextWave の見本では「現場名・稼働者：〇〇・稼働します」）。入れておくと、稼働日の当日にスタッフのマイページの「予定」と「報告」に「現場に着いたら」の欄が出て、コピー・LINE で送れます。2人以上の現場は全員の名前が入ります（代表の1人が送る）。空ならマイページに出ません
  - **現場の全員分をまとめる書式**: 「現場ごと」などに `{稼働者}` `{獲得した項目}` `{所感}` を使うと、2人以上の現場は全員分を1つにまとめた報告になります（NextWave の「代表者1名がまとめて報告」の形）

### ⑦-2-2 LINE に書いた報告を公認名称に直す（自動変換）

- **「実績確認 → 日報（LINE用）→ LINEの報告を変換」**: 取引先を選び、スタッフが LINE にいつもの書き方（キヘン・光・GOLD・プラチナ・MAX など）で書いた報告を貼ると、**その取引先の公認名称と書式**に直した文章が出ます。「コピー」で貼ってください
  - 項目名の当て方: 同じ名前 → 言いかえ表 → 推測。**✓（緑）**はそのまま、**「たぶん」（黄）**は推測なので確かめてください、**「選んでください」（赤）**は分からなかった書き方です。右の欄で選び直せます
  - 「（仮）」が付いた書き方（例: 光（仮））は、「（仮）」の項目（例: ドコモ光 1G（仮））に入ります
  - オーナーは、選び直した行の **「覚える」** を押すと、次からは自動でその項目になります（言いかえ表に入ります）
  - 「件数が読めなかった行」が出たら、「項目 件数」の形（例: キヘン 2、MAX×3）に直して貼り直してください
  - **NICOLY フォーマットも読めます**: 「10/11 現場名」（日付と現場が1行）、「新規1(山田)」（件数のあとに獲得した人）、「カード1」（間をあけない件数）、「当日」「後日」の見出し。「後日」の下の項目は「〇〇（後日）」の項目に入ります（なければ「選んでください」になるので、⑦-2-3 で（後日）の項目を作ってください）。項目の下の行（乗り換え元・端末など）は件数に入れず、メモとして残します
  - **実績に入れる（速報）**: 変換の下の「実績に入れる」で、日付と現場（貼った文の日付・現場名で選んであります）と、だれの報告にするか（「(山田)」の名前で選んであります）を確かめて「○人分を速報で入れる」。メモと所感はコメントに入ります。本人がもう報告している人・確定ずみの人には入れません。確定はいつもどおり「実績確認」で
- **言いかえ表（オーナー）**: 「設定 → 日報のフォーマット」のいちばん下。取引先・いつもの書き方・公認名称を選んで「足す」。ごみ箱で消せます。CRM に入った実績から日報を作るときも、ここにある名前は公認名称に直します

### ⑦-2-3 取引先の獲得項目をまとめて登録する（オーナー）

- **「設定 → 獲得項目 → まとめて登録する（一覧を貼る）」**: 取引先からもらった公認名称の一覧を1行に1つ貼ります（【】の見出しや「獲得名」の行は使いません。もうある名前は作りません）
  - 「光・カードの項目には『（仮）』の項目も作る」がオンなら、光・カードの項目のすぐ下に（仮）の項目も作ります（仮申し込みを分けて数えるため。単価を入れなければ請求・報酬には入りません）
  - 「『（後日）』の項目も作る」をオンにすると、それぞれの項目のすぐ下に（後日）の項目も作ります（報告の「後日」の獲得を、当日と分けて数えるため。単価の扱いは（仮）と同じ）
  - 「この取引先の現場で使う項目にする」で取引先を選ぶと、その取引先の現場の報告にはこの項目だけが出ます
- 項目が多い取引先（12項目より多い）は、スタッフの報告画面に **「項目をさがす」** が出て、件数を入れた項目が上に並びます。実績確認の画面は件数のある項目だけが出て、「ほかの項目も出す」で全部出ます

### ⑦-3 オンライン研修の予約（日程調整）

TimeRex のように、研修を受ける人が空いている日時を選んで予約できます。**「その他 → 研修の予約」**（PC は左のメニュー）。

1. **枠を作る**: 「研修の枠を作る」→ **日付**（いくつでも押せます）→ **始まる時刻** → **1枠の長さ** → **続けて作る数**（例: 10:00 から 60分 × 3 で 10時・11時・12時の3枠）・**1枠の定員** →「〇枠を作る」
   - 「詳細」で研修の名前・**参加の URL**（Zoom・Google Meet など）・ご案内を入れられます。参加の URL は予約した人の控えの画面に「オンラインの研修に入る」ボタンで出ます
2. **予約用リンクを送る**: 右上の「予約用リンク」→ コピー / LINEで送る（リンクを作る・止める・作り直すのはオーナー）
3. 受ける人はリンクから日時を選んでお名前を入れるだけで予約できます（ログイン不要）。予約すると控えの画面が出て、そこから参加・Google カレンダーに追加・キャンセルができます
4. **予約を見る**: 日付ごとに枠と予約した人（名前・連絡先）が出ます。満席の枠は予約の画面で押せません
   - 電話などで受けたときは、枠の「予約を入れる」→ お名前。「控えを送る」で参加の URL とキャンセルの画面を LINE で送れます
   - 「取り消す」は間違えたら「元に戻す」で戻せます
   - 枠の名前・定員・参加の URL は「直す」。日時を変えるときは「止める」→ 新しく作る（止めた枠は予約の画面に出ません。入っている予約はそのまま）
- **Google カレンダーとつなぐ（オーナー、任意）**: 「カレンダー連携・設定」で、カレンダーの「共有」に表示されたメールアドレス（シートへの書き出しと同じもの）を「予定の変更」で追加し、カレンダー ID を貼って保存します（くわしくは docs/setup.md ⑩）。つなぐと、**予定が入っている時間の枠は予約の画面に出さず**、予約が入るとカレンダーに予定が入ります（キャンセルで消えます）

### ⑧ 交通費・経費を承認する

- **「その他 → 交通費・経費の承認」** →「承認」または「却下」。まとめて選んで承認もできます。間違えたら「元に戻す」。
- 日当は交通費込みなので、スタッフからの交通費の申請はありません（その他の経費だけ）。遠い現場は「遠方の上乗せ」で日当に足します（→ 単価の入れ方）。

### ⑨ 営業の活動を記録する（スマホで10秒）

電話・LINE・メール・訪問・商談のあとに記録します。ホームの「今日やること」、営業の一覧の各行、会社の画面の **「記録する」**、または右下の ＋ →「活動を記録」→ 会社を選ぶ、のどこからでも開けます。

1. **種類**（最初は「架電」が選ばれています）
2. **結果**（つながった / 不在 / 折り返し待ち / 資料送付 / アポ獲得 / 見送り）
3. （あれば）**一言メモ**
4. **次回アクション日**の「明日 / 3日後 / 1週間後」を押すと、**その場で記録されます**。別の日は「日付を指定する」。

- 「次にやること」は結果に合わせて最初から入っています（例: 不在 →「もう一度電話する」）。直してから日付を押してもかまいません。
- 先の予定が入っている会社では「いまの予定のまま（10/15(木)）で記録」も出ます。
- 結果に合わせて、ステータスも1段進めます（例: 未接触の会社とつながった → 接触済み、アポ獲得 → 商談設定、商談の記録 → 商談済み）。変えたくないときは「詳細」でステータスを選び直します。先方の担当者も「詳細」で選べます。
- 取引中・見送り以外の会社で「次回なしで記録」を押すと、次回アクション日を入れるよう促します（もう一度押せば次回なしで記録できます）。
- 記録したあと、画面の上に出る **「元に戻す」** で取り消せます（記録した本人が15分以内。会社の次回アクション・ステータスも記録前に戻ります）。

## 2-2. AI アシスタント

画面の上の **「AI」** を押すと、AI に話しかけられます（スマホは画面いっぱい、PC は右側に開きます。ほかの画面に移っても会話は残り、「新しい会話」で消えます）。

- **データの質問**: 「今日と明日の欠員は？」「青木さんの来週の予定は？」「先月の〇〇（取引先）の新規の件数は？」など。AI が CRM を調べて答えます
- **文面の下書き**: 「明日の現場の前日リマインドの文面を作って」「〇〇さんに稼働可能日の提出をお願いする文を」など。文面テンプレートの書き方に合わせます。答えの下の「コピー」「LINEで送る」で使えます
- **日報**: 「今日の日報を作って」で、取引先ごとの日報のフォーマットの文章を出します
- **使い方の案内**: 「研修の予約のしかたは？」など、このマニュアルに沿って答えます
- **LINE のスクショから登録**: 左下の画像のボタンでスクショを付けて送ると、AI が内容を読み取り、**確認カード**を出します
  - 読み取れるもの: 実績の報告（件数・コメント）→ 速報として入る / 稼働可能日 / 取引先からの現場の依頼 → 現場を作る / 営業のやりとり → 活動の記録 / 打診する人
  - カードの中身を確かめて **「登録する」** を押すまで、何も登録されません。違っていたら「やめる」を押して、AI に直し方を伝えてください
  - 実績の報告は「速報」として入ります。**確定は「実績確認」の画面**で行ってください（本人がもう報告している人は入れません）
  - 報告の項目名は、**言いかえ表**（「キヘン → 機種変更」など。⑦-2-2）に合わせて入れます。言いかえ表にない書き方で、どの項目か分からないときは AI が聞き返します
  - 取引先が「使う獲得項目」を決めているのに、その中にない項目を入れようとしていたら、カードに注意が出ます（例: ネクストウェーブの現場に公認名称でない項目）
  - 営業の記録と打診は、登録したあと「元に戻す」で戻せます
- **管理者には金額を答えません**（オーナーだけが聞けます）
- 電話番号・住所・口座は AI に渡しません。必要なときはスタッフの画面などで見てください
- AI は間違えることがあります。数字や名前は、大事なときは画面でも確かめてください
- 使うには、オーナーが Anthropic のキーを設定します（docs/setup.md ⑪）。設定がまだのときは「AI はまだ使えません」と出ます

## 2-3. LINE の自動のお知らせ

LINE 公式アカウントから、決まったときに自動でお知らせを送ります。**「その他 → LINE の通知」**（PC は左のメニュー）。使うには、オーナーが公式アカウントを用意します（docs/setup.md ⑫）。

| いつ | 誰に | 中身 |
|---|---|---|
| 打診中・補欠 → **確定**（本人が「参加できる」・画面で確定・稼働表で確定） | 確定したスタッフ本人 | 文面テンプレートの「確定連絡」（送ったら「確定連絡 送信済み」になる） |
| 同上 | 社内（オーナー・管理者のうち LINE とつないだ人。操作した本人を除く） | 【確定】日付・会場・名前・役割、あと何名か |
| **新しい現場**を作ったとき（1件・まとめて・複製・AI） | 社内（操作した本人を除く） | 【新しい現場】日付・会場・取引先・必要人数（まとめて作ったら1通） |
| **前日**の決めた時刻（初めは18時ごろ） | 翌日の現場の確定したスタッフ | 文面テンプレートの「前日リマインド」（1人1回。送ったら「リマインド 送信済み」） |
| 確定 → **キャンセル・当日不稼働**（今日以降の現場） | 社内（操作した本人を除く） | 【キャンセル】または【当日不稼働】日付・会場・名前・役割、今の欠員 |

- **つなぐ**: スタッフは**マイページの「お願い」のいちばん下の「LINE とつなぐ」**から本人がつなぎます（友だち追加 → コードを送る）。オーナー・管理者は「LINE の通知」の「自分の LINE」から同じようにつなぎます。つないだら「自分にテストを送る」で確かめられます
- **何を送るか（オーナー）**: 「LINE の通知 → 送るお知らせ」で、スタッフに確定 / スタッフに前日（時刻） / 社内に知らせる をそれぞれオン・オフします（初めはすべてオフ）
- お知らせは、操作してから**1分ほどあとに**届きます（間違えて確定して「元に戻す」を押したときは送りません）
- **送らないとき**: 月の稼働表の取り込み、辞退・キャンセルから確定に戻したとき、LINE とつながっていないスタッフ。つながっていない人には、今までどおり画面の「LINEで送る」で送ってください（ホームの「確定連絡 未送信」に出ます）
- 「LINE の通知」の画面で、つながっているスタッフの人数・まだの人・**送った記録**（送った / 送らなかった理由 / 送れなかった）が見られます
- 金額は送りません
- 料金: LINE 公式アカウントは月200通まで無料。それを超えると有料プラン（ライトプランは月5,000円で5,000通まで）。送る通数はスタッフ1人へのお知らせ1回で1通、社内へは人数分です

## 2-4. LINE の文を貼るだけ（LINE から入れる。Phase 18）

LINE に来た文を、ホームの「LINE の文を貼るだけ」か **「その他 → LINE から入れる」**（スマホは ＋ →「LINE の文を貼る」）に貼って「読み取る」を押すと、何の文かを見分けて、登録の確認を出します。**「登録する」を押すまで何も登録されません**。

| 貼る文 | 読み取ったあと |
|---|---|
| **件数の報告**（NICOLY フォーマット、「PI1」「キヘン2」などいつもの書き方） | 日付・会場・名前から現場と人を当てて、**速報の確認カード**を出します。項目名は言いかえ表（⑦-2-2）で合わせます。合わないときは「どの現場の報告か」「だれの報告か」を選んで読み直せます。確定は今までどおり「実績確認」で |
| **稼働可能日**（「11/1 ○ 11/2 ×」「1,2,5 ○ / 10 △ / 他は×」「○: 1 2 3」「12月は全部○」など） | 読めた日と印が出るので、**だれの分か選ぶ**と確認カードが出ます。月が書いてなければ、集めている月（翌月）として読みます |
| **打診の返事**（「参加できます」「無理です」のような短い文） | **返事待ちの打診の一覧**が出るので、その人の「確定」「辞退」を押します（元に戻せます） |
| **募集の文**（取引先からの「〈募集日〉11/1・5・6 ■稼働場所 …」） | 「現場を作る画面で続ける」で、文が入った状態の「募集の文から作る」が開きます（→ ②） |
| **案件詳細**（【案件詳細】●集合場所 …） | 会場を選んで「会場のメモに入れる」（稼働日程・稼働メンバー・電話番号の行は入れません） |
| 上のどれでもない文 | 「AI に読んでもらう」で AI アシスタントに渡せます（AI の設定があるとき。→ 2-2） |

- **LINE から転送する**: LINE 公式アカウント（2-3）を用意していて、自分の LINE を CRM とつないであれば、LINE でその文を長押し → **転送** → 公式アカウントを選ぶだけで、「LINE から入れる」の **「LINE から転送された文」** に入ります（返事に CRM のリンクが届きます）。画面で「読み取る」を押して登録します。つないでいない人からの文は入りません
- 読み取りはいつもの書き方を CRM の中で行うので、AI の設定がなくても動きます。AI に渡すのは「読めない文」だけです
- 金額は読みません・入れません

## 3. 毎月の流れ

### 稼働可能日の回収（初期値: 毎月10日締めで翌月分）

1. **「その他 → 稼働可能日の提出状況」**（翌月分が出ます）
2. **「全体向けの提出依頼」**→ スタッフの LINE グループに送る（各自のマイページから提出してもらうので、個別のリンクは不要）
3. 締切が近づいたら**「未提出の人に個別リマインド」**→ 1人ずつ LINE で送る
4. LINE で聞いた内容は「代理入力」で入れられます（入力元が「管理者」と記録されます）。**LINE の文（「11/1 ○ 11/2 ×」「1,2,5 ○ 他は×」など）をホームの「LINE の文を貼るだけ」に貼り、だれの分か選ぶ**のが早いです（→ 2-4）
5. いつものシートの「シフト」の行（⭕️🔺❌。確定した日は ⭐️）に書いている場合は、シートを自動で読む設定（→ ②-4）にすると、10分以内に CRM にも入ります

### 月次締め・請求・支払い（オーナーのみ）

毎月の流れ（月末締め・翌月払い）:

1. 月が終わったら、**「お金 → 締め」**で前の月を選ぶ（「前の月」ボタン）
2. **締める前のチェック**を見る: 実績が未確定の現場・未報告のアサイン・未承認の交通費経費・単価や日当が未設定の件数が赤で出ます。件数を押すと、その画面へ移れます
3. **「この月を締める」**。未処理が残っていると一覧が出るので、確かめて「このまま締める」
   - 締めると、その月の請求額・支払額をその時点の金額で保存し、その月の実績・単価・経費・アサイン・現場は変更できなくなります
   - 支払いの状態が「確定（未払い）」になります
4. **「お金 → 書き出し」**で、請求集計・支払明細・freee 用 CSV・振込データをダウンロード（下の「書き出し」）
5. 振り込んだら、**「お金 → 支払い」**の上の「支払済みにする」で支払日（初期値は設定の支払日。「今日」も選べます）を選び、「確定の○人を支払済みにする」。1人ずつは、その人の明細を開いて「支払済みにする」。間違えたら画面の上に出る「元に戻す」

**締めたあとに直したいとき**: 「お金 → 締め」→「ロックを解除する」→ 理由を入れる（必須。履歴に残ります）→ 直す →「もう一度締める」。支払済みの状態と支払日はそのまま残ります。支払済みの人の金額が変わったときは知らせが出るので、差額は翌月の「調整額」で精算してください。

### お金の画面（オーナーのみ）

「お金」（PC は左のメニュー、スマホは「その他 → お金」）。上のタブで切り替え、「前の月 / 次の月」で月を変えます。

- **月次集計**: その月の売上（税抜）・支払（報酬＋交通費経費）・粗利と粗利率。**確定**（実績が確定した現場）と**見込み**（まだの現場は確定人数と速報件数で計算）に分けて出ます。目標との比較、12か月の推移（棒を押すと金額。「表で見る」もあります）、取引先別・会場別。単価や日当が入っていない現場があると赤で知らせます
- **請求**: 取引先ごとの請求額（税抜＋消費税＝税込）。押すと現場ごとの明細（人日 × 単価・成果 × 件数・現場固定・交通費）
- **支払い**: スタッフごとの差引支払額（日当＋インセンティブ＋調整額＋交通費経費−源泉）と明細、インボイス登録の有無、支払いの状態（未確定 / 確定（未払い）/ 支払済）。**調整額**（＋/−、理由は必須）はここで足します（締めた月は変えられません）
- **支払明細書**: 「お金 → 支払い」の右上の **「支払明細書（PDF）」**。今までの書式と同じ「支払一覧表」（氏名・ランク・単価・稼働数・合計（税込）・うち本体価格・源泉徴収税額・お支払額）が出ます。名前を押すと一人ずつの明細書（業務委託報酬（ランク）・遠方の上乗せ・インセンティブ・調整額・交通費経費 → 合計 → 本体価格・消費税 → 源泉 → お支払額）
  - **「PDF に保存（印刷）」** で保存して、LINE などで本人に送れます（スマホは共有 →「PDF」、PC は送信先「PDF に保存」）。「全員分の明細書を開く」→「全員分を PDF に保存」で、一覧のあとに1人1枚ずつの PDF になります
  - 締める前の月（今月など）は **「仮」** と出ます（実績の確定・締めのあとに変わることがあります）。締めた月は締めた時点の金額です
  - 会社名は「設定 → 締切・会社情報」の会社名が出ます（「株式会社NICOLY」のように入れてください）
- **締め**・**書き出し**: 上の「毎月の流れ」のとおり
- ホームの**「今月の数字」**と、稼働表の右端の**「売上・報酬」**の列もオーナーだけに出ます
- 締めた月は「締め済み（締めた時点の金額）」と出て、締めたときに保存した金額で表示します

### 単価の入れ方（オーナーのみ）

- **取引先の標準単価**: 営業 → 取引先 →「請求設定・標準単価（オーナーのみ）」。役割ごとの人日単価・現場固定・獲得項目ごとの成果単価、交通費を請求に含めるか。会場ごとに違う単価は「会場ごとの単価」から
- **現場だけの単価・日当**: 現場の詳細の下「単価（この現場だけ・オーナーのみ）」。空の欄は標準を使います。その現場の請求・報酬・粗利の見込みもここに出ます
- **日当はランクで決まります**: 設定 → ランク で、ランクごとの「基準日当」を入れます（「ランク制度のご案内」の額を入れます。P（パートナー）は空のまま）。ランクを上げると、その人の日当も変わります
- **人ごとの日当**: ランクの額と違う人だけ、スタッフの詳細 →「お金・契約」の「人ごとの日当」に入れます（入れた人はランクを変えても変わりません。ランクに合わせるときは空にして保存）。P（パートナー）の人はここに入れてください
- 日当は「この現場の日当 → 人ごとの日当 → ランクの基準日当」の順に使います。どれもない人は「日当が未設定」と赤く出ます
- **遠方の上乗せ**: 最寄り駅から現場まで1時間30分を超えるときは、現場の詳細で人の「…」→「最寄り駅から現場までの時間」（2時間まで・2時間30分まで…）を選びます（管理者も選べます。金額は出ません）。30分ごとに、お金の設定の「遠方の上乗せ」の額を日当に足します
- **友達紹介のボーナス**: スタッフの編集 → 詳細 →「紹介してくれた人」を選んでおきます。紹介された人が決めた回数（お金の設定。初期値5回）稼働すると、「お金 → 支払い」の上に「友達紹介のボーナス」が出るので、「〇〇円を足す」でその月の調整額に足します（1人につき1回。調整額を消せば、もう一度足せます）
- 単価は「この現場 → 取引先×会場 → 取引先」の順に、インセンティブは「この現場 → 全体」の順に使います
- **お金の設定**（設定 → お金の設定）: インセンティブ単価（全体）、消費税（率・端数）、源泉徴収（交通費を含めるか・税込/税抜。初期値は今までの明細書と同じ「本体価格（税抜）に 10.21%・控除なし」）、報酬の支払日（翌月の何日）、遠方の上乗せ（30分ごとの額）、友達紹介のボーナス（額と回数）、freee の勘定科目・税区分、振込データの振込元。**税・源泉の扱いは税理士に確認してください**
- **月次目標**（設定 → 月次目標）: 月ごとの売上・粗利の目標

### 書き出し（オーナーのみ）

「お金 → 書き出し」。ファイルはダウンロードされます。

- **請求集計（CSV）**・**支払明細（CSV）**: Excel で開けます。締めていない月は、見込みを含むいまの金額です
- **freee 用 CSV**（締めた月だけ）: freee 会計の「取引のインポート」で取り込みます。請求は「収入」（売上高・課税売上10%）、報酬は「支出」（外注費・交通費経費・源泉の預り金をまとめた1つの取引）で、どちらも未決済で入ります。勘定科目・税区分は「お金の設定」で freee に登録してある名前に合わせてください
- **振込データ（全銀フォーマット）**（締めた月だけ）: ネットバンキングの「総合振込」で読み込むファイルです。確定で未払いの人だけが入り、振込指定日は設定の支払日です
  - 先に「お金の設定」で振込元（委託者コード・銀行番号・支店番号・口座番号など）を入れてください
  - スタッフの「お金・契約」に**銀行番号（4桁）・支店番号（3桁）・口座名義（カナ）**が必要です。足りない人は画面に名前が出て、ファイルには入りません
- **全データ（バックアップ）**: すべての表を CSV にして ZIP にまとめます。口座・金額が入るので大切に保管してください（マイページの鍵などは入りません。領収書の写真は入りません）

### 会社の経費（オーナーのみ）

オーナーが立て替えた会社の経費（飲食・交通・通信・ソフト・備品など）を記録します（今までの「経費記録」のスプレッドシートの代わり）。スタッフが現場ごとに申請する「交通費・経費」とは別のものです。PC は左のメニュー「会社の経費」、スマホは「その他 → 会社の経費」。スマホのホーム・現場・営業の右下の ＋ →「経費を入れる」からもすぐ開けます。

**レシートを撮って入れる（いちばん早い）**
1. 「経費を入れる」→ **「レシートを撮る」**（前に撮った写真なら「写真を選ぶ」）
2. AI が**日付・店・金額（税込）・区分**を読み取って入れます。合っているか確かめて、違うところだけ直します
3. **「登録する」**。画面が空になるので、次のレシートを続けて撮れます
- 撮った写真は領収書として残り、一覧でカメラの印が付いた経費を開くと見られます。**紙の領収書は今までどおり取っておいてください**（CRM の写真は確認用です）
- AI が使えるように設定されていないとき（AI アシスタントと同じ設定）は、写真だけ残して手で入れます

**手で入れる**: 金額 → 区分（押すだけ。ない区分は「ほかの区分」）→ 店・支払先（前に入れた店が候補に出ます）→「登録する」
- 日付は**今日**、払った人は**自分**が最初から入っています（「昨日」・日付の指定、もう1人のオーナー・「まだ決めていない」も選べます）
- **飲食**を選ぶと「参加者」の欄が出ます。だれと行ったかを入れておくと、あとで経理が困りません
- 買ったもの・用途・メモは「詳細」に入れます

**間違えたとき**: 登録した直後なら、画面の上に出る「元に戻す」。あとからは一覧で押して直すか、「この経費を取り消す」（合計に入らなくなります。記録は消えずに残り、変更履歴にも残ります）

**一覧**: 月ごとに、**合計（税込）と件数**（今のシートの「合計金額・記録件数」と同じ）、**払った人ごと・区分ごと**の合計が出ます。「前の月 / 次の月」で月を変えます。

**今のスプレッドシートから取り込む**（はじめの1回）: 「取り込み・書き出し」→
- スプレッドシートの URL を貼って「全部のシートを読む」（シートへの書き出しと同じ Google のアカウントを、シートの共有に「閲覧者」で入れておきます）、または、シートを1枚ずつ「ファイル → ダウンロード → カンマ区切り形式（.csv）」で保存して「CSV ファイルを選ぶ」（何枚でもまとめて選べます）
- シートごとに件数・合計と、**「✓ シートの合計と同じ」**が出ます。「だれが払った分か」はシートの名前から選んであります（「未振分」は「まだ決めていない」）。違えば選び直します
- 日付・金額のない行は「入れない行」に理由が出ます（入れたいときはシートを直してからもう一度）
- 「〇件を取り込む」。**同じシートをもう一度取り込んでも、同じ経費は増えません**
- 取り込んだら、これからは CRM で入れてください（シートには書き足されません）

**書き出し**: 「取り込み・書き出し」の「〇月の分」「〇年の1年分」で CSV（Excel で開けます）。日付・払った人・区分・店・買ったもの・用途・参加者・金額・メモ・領収書の順で、最後に合計の行が入ります。税理士さんに渡すときに使います

## 4. スタッフの管理

- **登録**: スタッフ →「＋ 登録」→ 氏名・ランク・役割など。オーナーが登録するときは、基本日当にランクの基準日当が自動で入ります。
- **マイページ URL**: スタッフの詳細 →「マイページURL」→「LINEで送る」/「コピー」。一度送ればずっと使えます。
  - URL が他人に知られたときは「URLを再発行」（古い URL はすぐ使えなくなるので、新しい URL を本人に送ってください）。
- **メモ**: スタッフの詳細の「メモ」。名簿から取り込んだキャッチ力・クローザー力・知識・誓約書などは、**スキル・経験 / 実績 / 人柄・強み / 手続き / 連絡先 / そのほか** に分けた表で出ます（済・○は緑、未は黄色）。備考や「項目名: 」のない文章は、上の灰色の枠に出ます。
  - 自分で書くときは、編集画面のメモに「項目名: 内容」を1行ずつ書くと、同じように表に分かれます（例: `キャッチ力: 4`）。
- **アカデミーの進み具合**: スタッフの詳細の「アカデミー（いまのスキル）」に、NICOLY アカデミーの称号・稼働判断・分野ごとの進み具合（携帯・電気ガス・カード・光・端末のゲージ）・知識テスト・総合ロープレ・現場チェック・最後に学習した日が出ます。スタッフ一覧・打診の候補には帽子の札（称号・稼働判断。稼働可 = 緑・保留 = 黄・未判定 = 灰）が出ます。候補の並び順は変わりません。
  - 取り込み方: アカデミーの管理画面で「CSV」を押して保存 → CRM のスタッフ →「アカデミー」→ ファイルを選ぶ → 受講者ごとにスタッフを選ぶ（前に取り込んだ人は同じ人、はじめての人は名前が合う人が最初から選ばれています）→「〇人を取り込む」。管理者もできます。
  - 取り込むたびに、いちばん新しい記録に置きかわります。研修のあとなど、好きなときに取り込んでください。
  - 「アカデミーの名前とちがいます」と出たら、選んだスタッフが合っているか確かめてください。CRM にいない人は「取り込まない」のままで大丈夫です。
- **NG**: 会場NG・取引先NG と理由を登録すると、候補一覧で警告が出ます。
- **稼働履歴メモ**: 遅延・トラブル・良かった点などを記録します。
- **お金・契約（オーナーのみ）**: 人ごとの日当・源泉の方式・インボイス登録番号・契約日・契約書 PDF・振込口座（振込データを作るときは銀行番号4桁・支店番号3桁・口座名義カナも入れてください）。源泉の方式は全員「報酬・料金（10.21%）」から始まります。対象外の人（会社など）だけ「なし」にしてください。

## 5. 会場・取引先・協力会社（営業）

- **会場**: 住所（地図が開きます）・最寄り駅・入館方法・控室・駐車場など。現場の詳細とスタッフのマイページにも出ます。「テレアポ」など会場以外の稼働も会場として登録できます。
  - **色**: 稼働表・ホームで使う会場の色（7色から選ぶ）。新しく登録するときは「おまかせ」で、使っている会場が少ない色が付きます。近くの会場や同じ日によく重なる会場は、違う色にしておくと見分けやすくなります。
- **営業の一覧**: 「取引先 / 協力会社」のタブと、**「リスト / カンバン」**（ステータスごとの列）の切り替え。
  - 並び順: ① 次回アクション日が今日以前（古い順・赤）→ ② 次回アクション未設定（赤の札）→ ③ 先の予定（近い順）→ ④ 予定のない取引中・見送り。
  - 絞り込み: ステータス・次回アクション（今日まで / 未設定）・担当者（自分 / 各担当者 / なし）・優先度。
  - ステータスは6段階: 未接触 → 接触済み → 商談設定 → 商談済み → 取引中 → 見送り・休眠。**取引中・見送り以外は「次回アクション日」と「次にやること」が必須**です。
- **会社の画面**: 次回アクションと「記録する」、**活動履歴**（いつ・誰が・何をして・どうなったか・次回をいつにしたか）、基本情報（電話はタップで発信）、先方の担当者（複数）、関連する現場（取引先）、関連資料のリンク、**使う獲得項目**（取引先。その取引先の現場で、スタッフの報告画面に出す項目。何も選ばなければ全項目）。
- 優先度・担当者・ステータスなどは「編集」から変えられます。ステータスの変更は変更履歴に残ります。

## 5-2. 実績の分析

「その他 → 実績の分析」（PC は左のメニュー）。ホームの「今月の獲得件数」の「くわしく」からも開けます。金額は出ません（管理者も同じ画面を使えます）。

- **スタッフ別 / 会場別 / 取引先別**に、獲得件数・**1稼働あたりの獲得件数**・稼働（延べ人数）・獲得項目ごとの件数を出します。会場別・取引先別は現場の数も出ます。
- 期間: 今月 / 先月 / 直近3か月 / 直近12か月。**確定 / 速報**の切り替え、**件数順 / 1稼働あたり順**の並び替えができます。
- 1稼働あたり = 獲得件数 ÷ 件数の分かる稼働（確定ベースは確定済み、速報ベースは報告済み）。まだ確定していない稼働は「未確定 ○」と黄色で出ます。中止の現場は数えません。
- 2人で取った件数を分けた分（0.5 件など）も、そのまま足して出します。LINE のトーク履歴から取り込んだ「記録のみ」の現場の件数も入ります。

## 6. 設定（オーナーのみ）

「その他 → 設定」

- **ユーザー**: 管理者の招待（ログイン用メールが届きます）・無効化（すぐにログインできなくなります）
- **役割 / 獲得項目 / ランク（基準日当）/ エリア**: 追加・名前変更・並び替え・無効化（過去のデータは残ります）
- **文面テンプレート**: 打診・確定連絡・前日リマインド・提出依頼など。`{名前}` などのボタンで差し込み項目を入れられ、プレビューで確認できます。
- **締切・会社情報**: 稼働可能日の締切日（初期値 毎月10日）、実績報告の期限、「日当は交通費込み」（オンのあいだ、マイページの報告に交通費の欄が出ません）
- **お金の設定・月次目標**: 上の「単価の入れ方」を見てください

## 7. データ取り込み（オーナーのみ）

「その他 → データ取り込み」→ 種類（スタッフ名簿 / 取引先 / 協力会社 / 会場）→ CSV ファイル → 列の対応（自動で選ばれます）→ 確認 → 取り込む

- Google スプレッドシートは「ファイル → ダウンロード → カンマ区切り形式（.csv）」で保存します。Excel の CSV も読めます。
- **スタッフ名簿（メンバー管理シート）**: キャッチ力・クローザー力・立ち回り・知識・メール・誓約書の列はメモにまとめて入ります。UPD_ID・整理番号は取り込みません。口座情報（1つのセル）は銀行・支店・種別・番号に分けて入ります。口座名義カナは入らないので、あとで入力してください。
- **シートを自動で読む**（画面のいちばん上）: 10分ごとに今月・来月のタブを読んで追いかけます。使い方は ②-4。これを使っていれば、下の「月の稼働表」を手で取り込む必要はありません
- **月の稼働表（今の管理用スプレッドシート）**: 「データ取り込み」→「月の稼働表」。**先にスタッフ名簿を取り込んでおいてください。**
  - **いちばん簡単**: 「Google スプレッドシートから直接読む」に管理用シートの URL を貼り（シートへの書き出し先にしていれば最初から入っています）→「月のタブを探す」→ 取り込みたい月（202611 など）を押す。シートへの書き出しと同じ Google の設定を使います
  - CSV でも取り込めます: 取り込みたい月のタブを開き、「ファイル → ダウンロード → カンマ区切り形式（.csv）」で保存したファイルを選びます
  - 上の段（単価・現場・人数）から現場・必要人数・請求単価・交通費別を、下の段（単価・場所・シフト）から確定した予定・日当・稼働可能日を作ります
  - シートには役割がないので、人数を入れる役割を選びます（初期値はいちばん上の役割）
  - 取引先・会場・スタッフは名前で自動で合わせます。合わないもの（「楽天イオンモール与野」と「楽天イオンモール与野ca」など）は確認画面で選び直せます。ないものは新しく作ります（住所などはあとで入力）
  - 名簿にいない人、上の段にない場所（研修など。取引先を選べば現場として作れます）、マイナスの単価は取り込みません。理由は確認画面の「取り込まないもの・注意」に出ます
  - **今日より前の日は「記録のみ」**（実績報告なし）で入ります。未報告としてホームなどに出ません
  - 同じ月をもう一度取り込んでも重なりません（すでにある現場は使い回し、入っている人・本人が出した稼働可能日はそのまま）
- **LINE のトーク履歴（過去の件数の報告）**: 「データ取り込み」→「LINEのトーク履歴（過去の件数の報告）」。件数の報告をしている LINE グループの過去の報告を、**確定した実績**として入れます。候補の「平均獲得件数」や「実績の分析」に入ります。**先にスタッフ名簿と会場を入れておいてください**（月の稼働表を取り込んでいれば入っています）。
  - トーク履歴の保存: スマホの LINE はトークの右上のメニュー →「設定」→「トーク履歴を送信」（メールや Google ドライブに送る）、パソコンの LINE はトークの右上のメニュー →「トーク履歴を保存」。できた .txt ファイルを選びます
  - 読み取りは画面の中だけで行い、**トーク履歴のファイルはサーバーに保存しません**。お客様のお名前（〇〇様）・予約の日時・乗り換えの説明の行は使いません
  - 数えるのは**当日の獲得**だけです。「見込み」「予約」「戻り予定」・所感・お店全体の実績・累計の下は数えません。応対数・合計の行も数えません
  - **2人以上で取った件数は人数で割ります**（「PI1（山田、佐藤）」は 0.5 件ずつ）。名前が並んだ報告で項目に名前がなければ、並んだ人数で割ります。名前のない報告は送った人の分です
  - 人・会場・項目は自動で選ばれます。「人」「会場」「項目」の一覧で、書き方ごとに選び直せます（「取り込まない」「数えない」も選べます）。他社のヘルパーなど名簿にいない人の分は入りません
  - その日・その会場に現場がなければ、**「記録のみ」の現場**を作って入れます（請求・報酬の計算には入りません）。そのときの取引先は「「記録のみ」の現場を作るときの取引先」で会場ごとに選べます（その会場でいちばん多い取引先が最初から選ばれています）
  - もう実績がある人・確定していない（打診中など）人には入れません。**同じファイルをもう一度取り込んでも二重になりません**（「もう実績があります」と出ます）。今日より後の日も入れません
  - 入らなかった報告は理由ごとに出ます（会場を選んでいません・数える項目がありません・人を選んでいません など）。会場が CRM にないときは「会場」の画面で作ってから、もう一度ファイルを選んでください
  - 【案件詳細】の投稿（集合・入店のしかた・服装・持ち物）は「現場詳細」で選んで**会場のメモに入れられます**（会場ごとに一番新しいもの。稼働日程・稼働メンバー・電話番号の行は入れません）。ノート（[ノート]）は保存したトーク履歴に最初の100文字ほどしか入らないので使いません
- **メンバー名簿・スキルシート（Excel）**: Google ドライブで開き、下のタブで「メンバー名簿」を選んでから「ファイル → ダウンロード → カンマ区切り形式（.csv）」で保存します（一人ずつのスキルシートのタブは使いません）。
  - 「ランク(11月表)」がランクに入ります。「旧ランク(名簿)」・経験・実績・人柄・強み・口座登録・誓約書・要確認メモなどはメモにまとめて入ります。
  - 性別・生年月日・最終学歴・現住所・緊急連絡先・区分・〇月稼働日数は、自動では選ばれません。メモに入れたい場合は、列の対応の画面で「メモ」の列名をタップして選んでください。
- **アカデミーの進み具合**: 「データ取り込み」→「アカデミーの進み具合」（スタッフ →「アカデミー」と同じ画面）。取り込み方は「4. スタッフの管理」を見てください。
- **重複**: スタッフは電話番号、会社は会社名（「株式会社」「(株)」の違いは無視）、会場は会場名で判定します。チェックを入れた行だけ上書きします。

## 8. 変更履歴（オーナーのみ）

「その他 → 変更履歴」: アサインの状態・実績・経費・営業ステータス・お金関係の変更を、誰が・いつ・何から何に変えたかで確認できます。マイページからの変更は「（マイページ）」と表示されます。

## よくある質問

| 困りごと | 対応 |
|---|---|
| PC で「LINEで送る」ボタンが出ない | PC 版 LINE ではこの方式が使えないため、「コピー」して LINE に貼り付けてください |
| スタッフがマイページの URL をなくした | スタッフの詳細 → マイページURL →「LINEで送る」でもう一度送ります（再発行は不要） |
| スタッフが「参加できる」を押し間違えた | 現場の詳細のアサイン一覧で「…」→ 状態を変えます |
| 実績を確定したあとに修正したい | 実績確認 →「修正する」。履歴が残ります |
| 管理者を辞めた人がいる | 設定 → ユーザー → 有効をオフ（すぐにログインできなくなります） |
| 活動の記録を間違えた | 記録した直後なら、画面の上に出る「元に戻す」。時間がたったら、もう一度正しい内容で記録してください（活動履歴は消さずに残します） |
| 「締め済みのため変更できません」と出る | その月は締めてあります。お金 → 締め →「ロックを解除する」（理由が必要）で直せるようにして、直したら「もう一度締める」 |
| お金の数字がおかしい（0円・とても小さい） | 単価・日当が入っていない可能性があります。お金 → 月次集計の赤い知らせ、または締めのチェックを見てください |
| 振込データに入らない人がいる | お金 → 書き出し に理由（銀行番号・支店番号・口座名義カナが足りない など）が出ます。スタッフの「お金・契約」で入れてください。支払済みの人・差引0円以下の人は入りません |
| 稼働表やシートにスタッフの名前が出ない | 稼働表の「スタッフ（〇人）」が 0人なら、スタッフが登録されていないか、全員が休止・終了です。「データ取り込み」でスタッフ名簿を取り込むか、「スタッフ」の画面で状態を「すべて」にして確かめてください（稼働表に出るのは稼働中の人と、その月に予定がある人です）。名前は出ているのにマスが空のときは、月の稼働表を取り込むときに「取り込まない」になった人です。取り込み直して、名簿の人を選んでください |
| ホームの「今日やること」が多すぎる | 営業の一覧で「次回アクション: 次回 今日まで」「担当 自分」に絞り込むと、自分の分だけ見られます |
