# NICOLY CRM 操作マニュアル（オーナー・管理者向け）

Phase 3（お金: 単価・請求・支払い・月次締め・書き出し）時点の内容です。お金の画面と金額はオーナーだけが見られます（管理者には出ません）。

---

## 1. はじめに

### ログイン

- アプリの URL を開き、**「Google でログイン」**（招待されたメールアドレスの Google アカウント）を押します。
- Google アカウントがない場合は、メールアドレスを入れて**「ログイン用のリンクを受け取る」**→ 届いたメールのリンクを押します。
- ホーム画面に追加すると、アプリのように開けます（iPhone: 共有ボタン →「ホーム画面に追加」/ Android: メニュー →「ホーム画面に追加」）。

### 画面の見方

| | スマホ | PC |
|---|---|---|
| メニュー | 下のタブ「ホーム / 現場 / スタッフ / 営業 / その他」 | 左のメニュー |
| 現場を作る・活動を記録 | ホーム・現場一覧・営業の右下の ＋ →「現場を作る」/「活動を記録」 | 現場一覧の「＋ 現場を作る」、会社の画面の「記録する」 |
| 検索 | 上の検索窓（名前・会社・会場・電話番号。ひらがな / カタカナ、ハイフンの有無はどちらでも可） | 同じ |

**色の意味**: 赤 = 要対応（欠員・未報告など）、黄 = 待ち（打診中・未提出など）、緑 = 完了。

**オーナーと管理者の違い**: 管理者には金額（日当・単価・口座など）が一切表示されません。設定・データ取り込み・変更履歴はオーナーだけが使えます。

## 2. 毎日の流れ

### ① ホームで「要対応」を見る

ホームには、やるべきことがまとめて出ます。押すとその画面に移ります。

- **7日以内で欠員のある現場** → 押すと「候補を探す」が開きます
- **未回答の打診**（24時間以上たったものは赤）
- **明日の現場で前日リマインドを送っていない**
- **実績の未報告**（稼働日を過ぎてもスタッフが報告していない）
- **未承認の交通費・経費**
- **翌月分の稼働可能日の未提出**（締切を過ぎると赤）

その下の **「今日やること（営業）」** には、次回アクション日が今日以前の取引先・協力会社が出ます（過ぎたものは赤）。電話したら、その行の「記録」から記録します（→ ⑨）。

### ② 現場を作る

- **1日だけ**: ＋ →「現場を作る」→ 取引先・会場・日付・時間・役割ごとの必要人数 →「現場を作る」
- **まとめて**: 現場一覧 →「まとめて作る」→「来週の土日」などを押す（期間と曜日も選べます）→ 作らない日はタップで外す →「○件の現場を作る」
  - まとめて作った現場は「グループ」になり、グループごとに一覧できます。
- **別の日にコピー**: 現場の詳細 →「複製」→ 日付を選ぶ
- 服装・持ち物・注意事項・集合場所は「詳細」を開いて入れます（スタッフへの文面に入ります）。

### ②-2 稼働表で月全体を見る（今のシートと同じ形）

「現場」→ 上の切り替えで**「稼働表」**。今の月のスプレッドシートと同じ並びで、月全体を見渡せます。

- **上の段（現場）**: 取引先ごとに、その日の会場と「確定/必要人数」。**赤 = 欠員あり**、緑 = 埋まっている。「打1」は打診中の人数
  - マスを押すと、その現場の詳細が開きます。空いたマスを押すと、その日・その取引先で「現場を作る」が開きます
- **下の段（スタッフ）**: ランク順に、その日の予定。**緑 = 確定**、**黄（打）= 打診中**、灰（補）= 補欠、○△× = 稼働可能日。右端は確定した稼働日数
- スタッフのマスを押すと:
  - **稼働可能日**の代理入力（○・△・×・未入力）
  - **その日の現場**への「打診する（LINE）」「確定にする」。×の日・同じ日に別の現場・会場/取引先NG・役割が埋まっているときは赤い注意が出ます
  - 押したあとに出る「元に戻す」で取り消せます
- 名前の列と日付の行は固定です。表の中を指で上下左右に動かせます
- **拡大・縮小**（スプレッドシートと同じ感覚で、表の中だけ大きさが変わります）
  - スマホ: 表の中を **2本指でつまむ / 広げる**（画面全体は拡大されません）
  - PC: **Ctrl（Mac は ⌘ でも可）を押しながらマウスのホイール**、またはトラックパッドでつまむ
  - 表の上の **− / ＋** でも変えられます（25%〜200%）。真ん中の「100%」などの数字を押すと元の大きさに戻ります
  - 倍率はその端末に覚えておくので、次に開いたときも同じ大きさです
- **全画面**: 表の上の「全画面」を押すと、画面いっぱいに表だけが出ます（ページの上に表を重ねて出す形）。「閉じる」（PC は Esc キーでも可）で元の画面に戻ります。全画面のままマスを押して打診・確定もできます
- **スプレッドシートと同じ操作**（主に PC）
  - マスを押すと、そのマスに青い枠が付き、**その行と列に色が付きます**（日付と名前の見出しも太字になります）
  - **矢印キー**で移動、**Shift＋矢印**か**マウスでドラッグ**で範囲を選べます（Ctrl＋矢印で端まで、Ctrl＋A で全体）。**Enter** でマスを開きます（押したときと同じ画面）
  - **Ctrl＋C**（Mac は ⌘＋C）で選んだ範囲をコピーし、ほかのスプレッドシートや LINE に貼り付けられます（PC は表の上の「コピー」でも可）。金額は入りません
  - スタッフのマスで **1 = ○、2 = △、3 = ×**（o・x でも可）を押すと、その日の稼働可能日がすぐ入り、次の日に進みます。範囲を選んでから押すとまとめて入ります。**Delete**（Backspace）で消します。画面の下の「元に戻す」で取り消せます
  - Esc で選択を外します（全画面のときは、もう一度 Esc で閉じます）
- **列の幅・行の高さ**
  - 見出しの右端（日付・「日付」の列）を**ドラッグ**すると、日付の列（まとめて）・名前の列の幅を変えられます。ダブルクリックで元の幅に戻ります
  - 表の上の「行の高さ」ボタン（中 → 小 → 大）で行を詰めたり広げたりできます。小にすると最寄り駅を隠して、会場名を1行にします
  - 幅・高さはその端末に覚えておきます
- 「前の月」「次の月」で月を変えられます

- **単価（オーナーのみ）**: 稼働表のマスに、現場の人日単価（例: ¥22,000。役割で違うときは ¥20,000〜25,000）と、スタッフの日当が小さく出ます（今のシートの「単価」の行と同じ情報）。行の高さを「小」にすると隠れます。管理者には出ません

### ②-3 見るだけリンク・シートへの書き出し（現場リーダー・スタッフへの共有）

稼働表の右上のボタンから使います。どちらも**金額・電話番号・打診中の情報は出ません**。

- **見るだけリンク**: ログインなしで稼働表を見られるリンクです。「LINEで送る」「コピー」で現場リーダー・スタッフに送ります。見るだけリンクの画面でも、2本指・− / ＋・全画面で拡大・縮小できます
  - 作る・止める・作り直すのはオーナーだけ。作り直すと古いリンクはすぐ使えなくなります（リンクが漏れたときに）
  - 見られるのは先月〜3か月先です
- **シートへの書き出し**: 稼働表（今月と来月）を、スプレッドシートの **「CRM 202610」「CRM 202611」のような CRM 専用のタブ**に**10分ごと**に自動で書き出します。見るだけ用です（シートで直しても CRM には戻りません）
  - 並びは今のシートと同じです（取引先・会場ごとに「単価 / 現場 / 人数」、スタッフごとに「単価 / 場所 / シフト」の3行）。ただし**単価の行は空**です（共有するシートに金額は出しません）
  - 最初にオーナーが書き出し先のスプレッドシートの URL を入れます（準備は setup.md ⑨）
  - **いつもの管理用シートを書き出し先にしても大丈夫です**。CRM は「CRM 〜」のタブにしか書かず、手で作った「202610」などのタブには触りません。同じ名前の「CRM 〜」タブを人が作っていたときは、上書きせずに止まります
  - 「今すぐ書き出す」で、すぐに最新にできます。最後に書き出した時刻と結果が出ます

### ③ 候補を探して打診する

1. 現場の詳細 →**「候補を探す」**
2. 打診する役割を選ぶ（欠員のある役割が最初から選ばれています）
3. 候補は **○ → △ → 未提出 → ×・NG・同日に別現場** の順に並びます。同じ順位の中はランク → 平均獲得件数の順です。
   - 赤い印: 同日に別現場 / 会場NG / 取引先NG / 注意（直前キャンセル・遅延などの回数）
   - 緑の「エリア一致」: 会場のエリアに対応できる人
4. 打診する人にチェック →**「打診する」**（NG などの人が入っていると確認が出ます）
5. 文面が1人ずつ出るので、**「LINEで送る」**→ LINE で本人を選んで送信。PC では**「コピー」**して LINE に貼り付けます。

### ④ 回答を待つ

- スタッフがマイページで「参加できる」を押すと、**自動で「確定」**になります（定員に達していたら「補欠」）。
- LINE で口頭の回答が来たときは、現場の詳細のアサイン一覧で名前の右の「…」→ 状態を選びます。間違えたら画面下の「元に戻す」。
- 欠員が埋まると、ホームの赤い表示が消えます。

### ⑤ 確定連絡・前日リマインド

- 現場の詳細 →**「確定連絡を送る」**→ 1人ずつ「LINEで送る」。送ると「確定連絡済み」になります。
- 前日（と当日）は**「前日リマインドを送る」**が出ます。送っていない人がいるとホームに出ます。

### ⑥ キャンセル・当日不稼働

- アサイン一覧の「…」→「キャンセル」または「当日不稼働」→ 理由を選ぶ。
- スタッフの**稼働履歴メモに自動で記録**されます（直前キャンセル・遅延などは、候補一覧の「注意」の回数に入ります）。

### ⑦ 実績を確定する

- スタッフは稼働日の夜〜7日後までに、マイページから件数・コメント・交通費を報告します（＝速報）。
- **「その他 → 実績確認」**: 現場ごとに、速報の件数が最初から入っています。
  - そのままでよければ**「速報どおり確定」**（現場ごとにまとめて）
  - 件数を変えるときは ＋ / − で直し、**差分の理由**（キャンセル / 否認 / 入力ミス / その他）を選んで「確定する」
  - 未報告の人は、LINE などで聞いた件数を入れて「代理で入力して確定」
  - 確定後も「修正する」で直せます。「履歴」で誰がいつ何から何に変えたかを確認できます。

### ⑦-2 日報を取引先ごとの書式で送る（LINE にコピー）

- **「実績確認」→ 右上の「日報（LINE用）」**: 日付（今日 / 昨日 / ‹ ›）を選ぶと、その日の取引先ごとに、報告の件数・コメントを**取引先の書式の文章**にして出します。「コピー」（スマホは「LINEで送る」も）で取引先の LINE に貼ります。
  - 件数は、確定していれば確定件数、まだなら速報です。報告していない人は「（未報告）」と出るので、集まってからコピーしてください
- **書式を作る・直す（オーナー）**: 「設定 → 日報のフォーマット」
  - 「新しいフォーマットを作る」→ 名前（例: NextWave用）・**使う取引先**（空なら全取引先）を選ぶ
  - 文面は4つの欄に分かれています。**はじめ**（最初に1回）→ **現場ごと**（会場ごとに1回）→ **1人ごと**（その現場の1人ごと）→ **おわり**（最後に1回）
  - 欄を押すと下に `{名前}` `{件数一覧}` `{件数:新規}` などのボタンが出ます。押すとその場所に入ります。右（スマホは下）のプレビューで出来上がりを確かめて「保存する」
  - 「スタッフのマイページにも出す」をオンにすると、スタッフが報告を送ったあと、マイページに同じ書式の「LINE用にコピー」が出ます（本人の分だけ）

### ⑦-3 オンライン研修の予約（日程調整）

TimeRex のように、研修を受ける人が空いている日時を選んで予約できます。**「その他 → 研修の予約」**（PC は左のメニュー）。

1. **枠を作る**: 「研修の枠を作る」→ **日付**（いくつでも押せます）→ **始まる時刻** → **1枠の長さ** → **続けて作る数**（例: 10:00 から 60分 × 3 で 10時・11時・12時の3枠）・**1枠の定員** →「〇枠を作る」
   - 「詳細」で研修の名前・**参加の URL**（Zoom・Google Meet など）・ご案内を入れられます。参加の URL は予約した人の控えの画面に「オンラインの研修に入る」ボタンで出ます
2. **予約用リンクを送る**: 右上の「予約用リンク」→ コピー / LINEで送る（リンクを作る・止める・作り直すのはオーナー）
3. 受ける人はリンクから日時を選んでお名前を入れるだけで予約できます（ログイン不要）。予約すると控えの画面が出て、そこから参加・Google カレンダーに追加・キャンセルができます
4. **予約を見る**: 日付ごとに枠と予約した人（名前・連絡先）が出ます。満席の枠は予約の画面で押せません
   - 電話などで受けたときは、枠の「予約を入れる」→ お名前。「控えを送る」で参加の URL とキャンセルの画面を LINE で送れます
   - 「取り消す」は間違えたら「元に戻す」で戻せます
   - 枠の名前・定員・参加の URL は「直す」。日時を変えるときは「止める」→ 新しく作る（止めた枠は予約の画面に出ません。入っている予約はそのまま）
- **Google カレンダーとつなぐ（オーナー、任意）**: 「カレンダー連携・設定」で、カレンダーの「共有」に表示されたメールアドレス（シートへの書き出しと同じもの）を「予定の変更」で追加し、カレンダー ID を貼って保存します（くわしくは docs/setup.md ⑩）。つなぐと、**予定が入っている時間の枠は予約の画面に出さず**、予約が入るとカレンダーに予定が入ります（キャンセルで消えます）

### ⑧ 交通費・経費を承認する

- **「その他 → 交通費・経費の承認」** →「承認」または「却下」。まとめて選んで承認もできます。間違えたら「元に戻す」。

### ⑨ 営業の活動を記録する（スマホで10秒）

電話・LINE・メール・訪問・商談のあとに記録します。ホームの「今日やること」、営業の一覧の各行、会社の画面の **「記録する」**、または右下の ＋ →「活動を記録」→ 会社を選ぶ、のどこからでも開けます。

1. **種類**（最初は「架電」が選ばれています）
2. **結果**（つながった / 不在 / 折り返し待ち / 資料送付 / アポ獲得 / 見送り）
3. （あれば）**一言メモ**
4. **次回アクション日**の「明日 / 3日後 / 1週間後」を押すと、**その場で記録されます**。別の日は「日付を指定する」。

- 「次にやること」は結果に合わせて最初から入っています（例: 不在 →「もう一度電話する」）。直してから日付を押してもかまいません。
- 先の予定が入っている会社では「いまの予定のまま（10/15(木)）で記録」も出ます。
- 結果に合わせて、ステータスも1段進めます（例: 未接触の会社とつながった → 接触済み、アポ獲得 → 商談設定、商談の記録 → 商談済み）。変えたくないときは「詳細」でステータスを選び直します。先方の担当者も「詳細」で選べます。
- 取引中・見送り以外の会社で「次回なしで記録」を押すと、次回アクション日を入れるよう促します（もう一度押せば次回なしで記録できます）。
- 記録したあと、画面の下に出る **「元に戻す」** で取り消せます（記録した本人が15分以内。会社の次回アクション・ステータスも記録前に戻ります）。

## 2-2. AI アシスタント

画面の上の **「AI」** を押すと、AI に話しかけられます（スマホは画面いっぱい、PC は右側に開きます。ほかの画面に移っても会話は残り、「新しい会話」で消えます）。

- **データの質問**: 「今日と明日の欠員は？」「青木さんの来週の予定は？」「先月の〇〇（取引先）の新規の件数は？」など。AI が CRM を調べて答えます
- **文面の下書き**: 「明日の現場の前日リマインドの文面を作って」「〇〇さんに稼働可能日の提出をお願いする文を」など。文面テンプレートの書き方に合わせます。答えの下の「コピー」「LINEで送る」で使えます
- **日報**: 「今日の日報を作って」で、取引先ごとの日報のフォーマットの文章を出します
- **使い方の案内**: 「研修の予約のしかたは？」など、このマニュアルに沿って答えます
- **LINE のスクショから登録**: 左下の画像のボタンでスクショを付けて送ると、AI が内容を読み取り、**確認カード**を出します
  - 読み取れるもの: 実績の報告（件数・コメント）→ 速報として入る / 稼働可能日 / 取引先からの現場の依頼 → 現場を作る / 営業のやりとり → 活動の記録 / 打診する人
  - カードの中身を確かめて **「登録する」** を押すまで、何も登録されません。違っていたら「やめる」を押して、AI に直し方を伝えてください
  - 実績の報告は「速報」として入ります。**確定は「実績確認」の画面**で行ってください（本人がもう報告している人は入れません）
  - 営業の記録と打診は、登録したあと「元に戻す」で戻せます
- **管理者には金額を答えません**（オーナーだけが聞けます）
- 電話番号・住所・口座は AI に渡しません。必要なときはスタッフの画面などで見てください
- AI は間違えることがあります。数字や名前は、大事なときは画面でも確かめてください
- 使うには、オーナーが Anthropic のキーを設定します（docs/setup.md ⑪）。設定がまだのときは「AI はまだ使えません」と出ます

## 2-3. LINE の自動のお知らせ

LINE 公式アカウントから、決まったときに自動でお知らせを送ります。**「その他 → LINE の通知」**（PC は左のメニュー）。使うには、オーナーが公式アカウントを用意します（docs/setup.md ⑫）。

| いつ | 誰に | 中身 |
|---|---|---|
| 打診中・補欠 → **確定**（本人が「参加できる」・画面で確定・稼働表で確定） | 確定したスタッフ本人 | 文面テンプレートの「確定連絡」（送ったら「確定連絡 送信済み」になる） |
| 同上 | 社内（オーナー・管理者のうち LINE とつないだ人。操作した本人を除く） | 【確定】日付・会場・名前・役割、あと何名か |
| **新しい現場**を作ったとき（1件・まとめて・複製・AI） | 社内（操作した本人を除く） | 【新しい現場】日付・会場・取引先・必要人数（まとめて作ったら1通） |
| **前日**の決めた時刻（初めは18時ごろ） | 翌日の現場の確定したスタッフ | 文面テンプレートの「前日リマインド」（1人1回。送ったら「リマインド 送信済み」） |

- **つなぐ**: スタッフは**マイページの「お願い」のいちばん下の「LINE とつなぐ」**から本人がつなぎます（友だち追加 → コードを送る）。オーナー・管理者は「LINE の通知」の「自分の LINE」から同じようにつなぎます。つないだら「自分にテストを送る」で確かめられます
- **何を送るか（オーナー）**: 「LINE の通知 → 送るお知らせ」で、スタッフに確定 / スタッフに前日（時刻） / 社内に知らせる をそれぞれオン・オフします（初めはすべてオフ）
- お知らせは、操作してから**1分ほどあとに**届きます（間違えて確定して「元に戻す」を押したときは送りません）
- **送らないとき**: 月の稼働表の取り込み、辞退・キャンセルから確定に戻したとき、LINE とつながっていないスタッフ。つながっていない人には、今までどおり画面の「LINEで送る」で送ってください（ホームの「確定連絡 未送信」に出ます）
- 「LINE の通知」の画面で、つながっているスタッフの人数・まだの人・**送った記録**（送った / 送らなかった理由 / 送れなかった）が見られます
- 金額は送りません
- 料金: LINE 公式アカウントは月200通まで無料。それを超えると有料プラン（ライトプランは月5,000円で5,000通まで）。送る通数はスタッフ1人へのお知らせ1回で1通、社内へは人数分です

## 3. 毎月の流れ

### 稼働可能日の回収（初期値: 毎月20日締めで翌月分）

1. **「その他 → 稼働可能日の提出状況」**（翌月分が出ます）
2. **「全体向けの提出依頼」**→ スタッフの LINE グループに送る（各自のマイページから提出してもらうので、個別のリンクは不要）
3. 締切が近づいたら**「未提出の人に個別リマインド」**→ 1人ずつ LINE で送る
4. LINE で聞いた内容は「代理入力」で入れられます（入力元が「管理者」と記録されます）

### 月次締め・請求・支払い（オーナーのみ）

毎月の流れ（月末締め・翌月払い）:

1. 月が終わったら、**「お金 → 締め」**で前の月を選ぶ（「前の月」ボタン）
2. **締める前のチェック**を見る: 実績が未確定の現場・未報告のアサイン・未承認の交通費経費・単価や日当が未設定の件数が赤で出ます。件数を押すと、その画面へ移れます
3. **「この月を締める」**。未処理が残っていると一覧が出るので、確かめて「このまま締める」
   - 締めると、その月の請求額・支払額をその時点の金額で保存し、その月の実績・単価・経費・アサイン・現場は変更できなくなります
   - 支払いの状態が「確定（未払い）」になります
4. **「お金 → 書き出し」**で、請求集計・支払明細・freee 用 CSV・振込データをダウンロード（下の「書き出し」）
5. 振り込んだら、**「お金 → 支払い」**の上の「支払済みにする」で支払日（初期値は設定の支払日。「今日」も選べます）を選び、「確定の○人を支払済みにする」。1人ずつは、その人の明細を開いて「支払済みにする」。間違えたら画面の下の「元に戻す」

**締めたあとに直したいとき**: 「お金 → 締め」→「ロックを解除する」→ 理由を入れる（必須。履歴に残ります）→ 直す →「もう一度締める」。支払済みの状態と支払日はそのまま残ります。支払済みの人の金額が変わったときは知らせが出るので、差額は翌月の「調整額」で精算してください。

### お金の画面（オーナーのみ）

「お金」（PC は左のメニュー、スマホは「その他 → お金」）。上のタブで切り替え、「前の月 / 次の月」で月を変えます。

- **月次集計**: その月の売上（税抜）・支払（報酬＋交通費経費）・粗利と粗利率。**確定**（実績が確定した現場）と**見込み**（まだの現場は確定人数と速報件数で計算）に分けて出ます。目標との比較、12か月の推移（棒を押すと金額。「表で見る」もあります）、取引先別・会場別。単価や日当が入っていない現場があると赤で知らせます
- **請求**: 取引先ごとの請求額（税抜＋消費税＝税込）。押すと現場ごとの明細（人日 × 単価・成果 × 件数・現場固定・交通費）
- **支払い**: スタッフごとの差引支払額（日当＋インセンティブ＋調整額＋交通費経費−源泉）と明細、インボイス登録の有無、支払いの状態（未確定 / 確定（未払い）/ 支払済）。**調整額**（＋/−、理由は必須）はここで足します（締めた月は変えられません）
- **締め**・**書き出し**: 上の「毎月の流れ」のとおり
- ホームの**「今月の数字」**と、稼働表の右端の**「売上・報酬」**の列もオーナーだけに出ます
- 締めた月は「締め済み（締めた時点の金額）」と出て、締めたときに保存した金額で表示します

### 単価の入れ方（オーナーのみ）

- **取引先の標準単価**: 営業 → 取引先 →「請求設定・標準単価（オーナーのみ）」。役割ごとの人日単価・現場固定・獲得項目ごとの成果単価、交通費を請求に含めるか。会場ごとに違う単価は「会場ごとの単価」から
- **現場だけの単価・日当**: 現場の詳細の下「単価（この現場だけ・オーナーのみ）」。空の欄は標準を使います。その現場の請求・報酬・粗利の見込みもここに出ます
- **スタッフの基本日当**: スタッフの詳細 →「お金・契約」
- 単価は「この現場 → 取引先×会場 → 取引先」の順に、インセンティブは「この現場 → 全体」の順に使います
- **お金の設定**（設定 → お金の設定）: インセンティブ単価（全体）、消費税（率・端数）、源泉徴収（交通費を含めるか・税込/税抜）、報酬の支払日（翌月の何日）、freee の勘定科目・税区分、振込データの振込元。**税・源泉の扱いは税理士に確認してください**
- **月次目標**（設定 → 月次目標）: 月ごとの売上・粗利の目標

### 書き出し（オーナーのみ）

「お金 → 書き出し」。ファイルはダウンロードされます。

- **請求集計（CSV）**・**支払明細（CSV）**: Excel で開けます。締めていない月は、見込みを含むいまの金額です
- **freee 用 CSV**（締めた月だけ）: freee 会計の「取引のインポート」で取り込みます。請求は「収入」（売上高・課税売上10%）、報酬は「支出」（外注費・交通費経費・源泉の預り金をまとめた1つの取引）で、どちらも未決済で入ります。勘定科目・税区分は「お金の設定」で freee に登録してある名前に合わせてください
- **振込データ（全銀フォーマット）**（締めた月だけ）: ネットバンキングの「総合振込」で読み込むファイルです。確定で未払いの人だけが入り、振込指定日は設定の支払日です
  - 先に「お金の設定」で振込元（委託者コード・銀行番号・支店番号・口座番号など）を入れてください
  - スタッフの「お金・契約」に**銀行番号（4桁）・支店番号（3桁）・口座名義（カナ）**が必要です。足りない人は画面に名前が出て、ファイルには入りません
- **全データ（バックアップ）**: すべての表を CSV にして ZIP にまとめます。口座・金額が入るので大切に保管してください（マイページの鍵などは入りません）

## 4. スタッフの管理

- **登録**: スタッフ →「＋ 登録」→ 氏名・ランク・役割など。オーナーが登録するときは、基本日当にランクの基準日当が自動で入ります。
- **マイページ URL**: スタッフの詳細 →「マイページURL」→「LINEで送る」/「コピー」。一度送ればずっと使えます。
  - URL が他人に知られたときは「URLを再発行」（古い URL はすぐ使えなくなるので、新しい URL を本人に送ってください）。
- **メモ**: スタッフの詳細の「メモ」。名簿から取り込んだキャッチ力・クローザー力・知識・誓約書などは、**スキル・経験 / 実績 / 人柄・強み / 手続き / 連絡先 / そのほか** に分けた表で出ます（済・○は緑、未は黄色）。備考や「項目名: 」のない文章は、上の灰色の枠に出ます。
  - 自分で書くときは、編集画面のメモに「項目名: 内容」を1行ずつ書くと、同じように表に分かれます（例: `キャッチ力: 4`）。
- **NG**: 会場NG・取引先NG と理由を登録すると、候補一覧で警告が出ます。
- **稼働履歴メモ**: 遅延・トラブル・良かった点などを記録します。
- **お金・契約（オーナーのみ）**: 基本日当・源泉の方式・インボイス登録番号・契約日・契約書 PDF・振込口座（振込データを作るときは銀行番号4桁・支店番号3桁・口座名義カナも入れてください）。

## 5. 会場・取引先・協力会社（営業）

- **会場**: 住所（地図が開きます）・最寄り駅・入館方法・控室・駐車場など。現場の詳細とスタッフのマイページにも出ます。「テレアポ」など会場以外の稼働も会場として登録できます。
- **営業の一覧**: 「取引先 / 協力会社」のタブと、**「リスト / カンバン」**（ステータスごとの列）の切り替え。
  - 並び順: ① 次回アクション日が今日以前（古い順・赤）→ ② 次回アクション未設定（赤の札）→ ③ 先の予定（近い順）→ ④ 予定のない取引中・見送り。
  - 絞り込み: ステータス・次回アクション（今日まで / 未設定）・担当者（自分 / 各担当者 / なし）・優先度。
  - ステータスは6段階: 未接触 → 接触済み → 商談設定 → 商談済み → 取引中 → 見送り・休眠。**取引中・見送り以外は「次回アクション日」と「次にやること」が必須**です。
- **会社の画面**: 次回アクションと「記録する」、**活動履歴**（いつ・誰が・何をして・どうなったか・次回をいつにしたか）、基本情報（電話はタップで発信）、先方の担当者（複数）、関連する現場（取引先）、関連資料のリンク、**使う獲得項目**（取引先。その取引先の現場で、スタッフの報告画面に出す項目。何も選ばなければ全項目）。
- 優先度・担当者・ステータスなどは「編集」から変えられます。ステータスの変更は変更履歴に残ります。

## 5-2. 実績の分析

「その他 → 実績の分析」（PC は左のメニュー）。ホームの「今月の獲得件数」の「くわしく」からも開けます。金額は出ません（管理者も同じ画面を使えます）。

- **スタッフ別 / 会場別 / 取引先別**に、獲得件数・**1稼働あたりの獲得件数**・稼働（延べ人数）・獲得項目ごとの件数を出します。会場別・取引先別は現場の数も出ます。
- 期間: 今月 / 先月 / 直近3か月 / 直近12か月。**確定 / 速報**の切り替え、**獲得件数の順 / 1稼働あたりの順**の並び替えができます。
- 1稼働あたり = 獲得件数 ÷ 件数の分かる稼働（確定ベースは確定済み、速報ベースは報告済み）。まだ確定していない稼働は「未確定 ○」と黄色で出ます。中止の現場は数えません。

## 6. 設定（オーナーのみ）

「その他 → 設定」

- **ユーザー**: 管理者の招待（ログイン用メールが届きます）・無効化（すぐにログインできなくなります）
- **役割 / 獲得項目 / ランク（基準日当）/ エリア**: 追加・名前変更・並び替え・無効化（過去のデータは残ります）
- **文面テンプレート**: 打診・確定連絡・前日リマインド・提出依頼など。`{名前}` などのボタンで差し込み項目を入れられ、プレビューで確認できます。
- **締切・会社情報**: 稼働可能日の締切日、実績報告の期限
- **お金の設定・月次目標**: 上の「単価の入れ方」を見てください

## 7. データ取り込み（オーナーのみ）

「その他 → データ取り込み」→ 種類（スタッフ名簿 / 取引先 / 協力会社 / 会場）→ CSV ファイル → 列の対応（自動で選ばれます）→ 確認 → 取り込む

- Google スプレッドシートは「ファイル → ダウンロード → カンマ区切り形式（.csv）」で保存します。Excel の CSV も読めます。
- **スタッフ名簿（メンバー管理シート）**: キャッチ力・クローザー力・立ち回り・知識・メール・誓約書の列はメモにまとめて入ります。UPD_ID・整理番号は取り込みません。口座情報（1つのセル）は銀行・支店・種別・番号に分けて入ります。口座名義カナは入らないので、あとで入力してください。
- **月の稼働表（今の管理用スプレッドシート）**: 「データ取り込み」→「月の稼働表」。**先にスタッフ名簿を取り込んでおいてください。**
  - **いちばん簡単**: 「Google スプレッドシートから直接読む」に管理用シートの URL を貼り（シートへの書き出し先にしていれば最初から入っています）→「月のタブを探す」→ 取り込みたい月（202611 など）を押す。シートへの書き出しと同じ Google の設定を使います
  - CSV でも取り込めます: 取り込みたい月のタブを開き、「ファイル → ダウンロード → カンマ区切り形式（.csv）」で保存したファイルを選びます
  - 上の段（単価・現場・人数）から現場・必要人数・請求単価・交通費別を、下の段（単価・場所・シフト）から確定した予定・日当・稼働可能日を作ります
  - シートには役割がないので、人数を入れる役割を選びます（初期値はいちばん上の役割）
  - 取引先・会場・スタッフは名前で自動で合わせます。合わないもの（「楽天イオンモール与野」と「楽天イオンモール与野ca」など）は確認画面で選び直せます。ないものは新しく作ります（住所などはあとで入力）
  - 名簿にいない人、上の段にない場所（研修など。取引先を選べば現場として作れます）、マイナスの単価は取り込みません。理由は確認画面の「取り込まないもの・注意」に出ます
  - **今日より前の日は「記録のみ」**（実績報告なし）で入ります。未報告としてホームなどに出ません
  - 同じ月をもう一度取り込んでも重なりません（すでにある現場は使い回し、入っている人・本人が出した稼働可能日はそのまま）
- **メンバー名簿・スキルシート（Excel）**: Google ドライブで開き、下のタブで「メンバー名簿」を選んでから「ファイル → ダウンロード → カンマ区切り形式（.csv）」で保存します（一人ずつのスキルシートのタブは使いません）。
  - 「ランク(11月表)」がランクに入ります。「旧ランク(名簿)」・経験・実績・人柄・強み・口座登録・誓約書・要確認メモなどはメモにまとめて入ります。
  - 性別・生年月日・最終学歴・現住所・緊急連絡先・区分・〇月稼働日数は、自動では選ばれません。メモに入れたい場合は、列の対応の画面で「メモ」の列名をタップして選んでください。
- **重複**: スタッフは電話番号、会社は会社名（「株式会社」「(株)」の違いは無視）、会場は会場名で判定します。チェックを入れた行だけ上書きします。

## 8. 変更履歴（オーナーのみ）

「その他 → 変更履歴」: アサインの状態・実績・経費・営業ステータス・お金関係の変更を、誰が・いつ・何から何に変えたかで確認できます。マイページからの変更は「（マイページ）」と表示されます。

## よくある質問

| 困りごと | 対応 |
|---|---|
| PC で「LINEで送る」ボタンが出ない | PC 版 LINE ではこの方式が使えないため、「コピー」して LINE に貼り付けてください |
| スタッフがマイページの URL をなくした | スタッフの詳細 → マイページURL →「LINEで送る」でもう一度送ります（再発行は不要） |
| スタッフが「参加できる」を押し間違えた | 現場の詳細のアサイン一覧で「…」→ 状態を変えます |
| 実績を確定したあとに修正したい | 実績確認 →「修正する」。履歴が残ります |
| 管理者を辞めた人がいる | 設定 → ユーザー → 有効をオフ（すぐにログインできなくなります） |
| 活動の記録を間違えた | 記録した直後なら、画面の下の「元に戻す」。時間がたったら、もう一度正しい内容で記録してください（活動履歴は消さずに残します） |
| 「締め済みのため変更できません」と出る | その月は締めてあります。お金 → 締め →「ロックを解除する」（理由が必要）で直せるようにして、直したら「もう一度締める」 |
| お金の数字がおかしい（0円・とても小さい） | 単価・日当が入っていない可能性があります。お金 → 月次集計の赤い知らせ、または締めのチェックを見てください |
| 振込データに入らない人がいる | お金 → 書き出し に理由（銀行番号・支店番号・口座名義カナが足りない など）が出ます。スタッフの「お金・契約」で入れてください。支払済みの人・差引0円以下の人は入りません |
| 稼働表やシートにスタッフの名前が出ない | 稼働表の「スタッフ（〇人）」が 0人なら、スタッフが登録されていないか、全員が休止・終了です。「データ取り込み」でスタッフ名簿を取り込むか、「スタッフ」の画面で状態を「すべて」にして確かめてください（稼働表に出るのは稼働中の人と、その月に予定がある人です）。名前は出ているのにマスが空のときは、月の稼働表を取り込むときに「取り込まない」になった人です。取り込み直して、名簿の人を選んでください |
| ホームの「今日やること」が多すぎる | 営業の一覧で「次回アクション: 次回 今日まで」「担当 自分」に絞り込むと、自分の分だけ見られます |
