## Phase 3: お金 — 完了

お金の画面・設定は**すべてオーナーだけ**（管理者には出さない・データも取らない）。計算は `src/lib/money` の1か所にまとめ、要件 §10 の計算テストケース8件をすべてテストに入れる。

| 区切り | 内容 | 終わったら確認できること |
|---|---|---|
| 3-1 計算 | `src/lib/money`: 単価の選び方（現場の上書き → 取引先×会場 → 取引先）、請求（人日・現場固定・成果・交通費、消費税）、支払い（日当・インセンティブ・調整・交通費経費・源泉・差引）、見込み、粗利 | 計算テストケース8件が通る |
| 3-2 単価・設定の画面 | 取引先の「請求設定・標準単価」（会場ごとの標準も）、現場の「この現場の単価」（上書き・インセンティブの上書き・日当の上書き）、設定の「インセンティブ単価」「税・源泉」「支払日」「月次目標」 | 単価を入れると、その月の請求・支払いの見込みが出る |
| 3-3 お金の画面 | 今月の売上・支払・粗利（確定分と見込み分）、目標との比較、12か月の推移、取引先別・会場別。請求（取引先別＋現場ごとの明細）、支払い（スタッフ別＋明細・インボイス登録の有無・調整額・支払済）。ホームの「今月の数字」 | 月の請求額・支払額・粗利が一目で分かる |
| 3-4 月次締め | チェックリスト（未確定の実績・未承認の経費・未報告）→ 締める（請求・支払いを保存し、その月を変更できなくする）→ ロック解除（理由）→ もう一度締める | 締めた月は直せず、解除すると直せる |
| 3-5 出力 | 請求集計 CSV・支払明細 CSV（Excel で文字化けしない）、freee の「取引のインポート」用 CSV（勘定科目などは設定で変えられる）、全銀フォーマットの総合振込データ | Excel・freee・ネットバンキングに取り込める |

**決めたこと（2026-10-11）**
- 請求は**すべて月末締め**（1日〜末日）。取引先の締め日は使わない
- freee を使っている → freee の最新のヘルプで「取引のインポート」の形を確かめて作り、最後に一緒に取り込みを試す
- 全銀フォーマットの振込データを作る（振込元の口座・委託者コードはオーナーが設定画面で入れる。スタッフの口座には銀行・支店の番号が要る）
- 支払いは**翌月の決まった日**（日にちは設定で変えられる）

**作りながら決めたこと**
- 締めた月の画面は、締めたときに保存した金額（スナップショット）で出す。単価を後から変えても締めた月の数字は変わらない
- まだ終わっていない月は締められない（翌月1日から）。未処理があるときは一覧を出して確かめてから締める
- 締めた月は、実績・単価・経費・アサインに加えて現場（中止・日付など）も変更できない
- 支払いの状態: 未確定 → 確定（締めたとき）→ 支払済（支払日）。ロック解除で「確定」は「未確定」に戻る。もう一度締めても支払済みは残り、金額が変わった人を知らせる（差額は翌月の調整額で）
- freee: 請求は「収入」、報酬は「支出」の複数行（報酬・交通費経費・源泉の預り金をマイナス）。どちらも未決済。インボイス登録なしの人の税区分は、空なら発生日で自動（2026年9月まで 控80、10月から 控50）
- 振込データ: 締めた月・確定で未払い・差引1円以上の人だけ。口座の情報が足りない人は画面で名前を出して除く
- 全データの一括ダウンロード（要件 §7 バックアップ）を「書き出し」に入れた
- 稼働表の金額の列は「売上・報酬」（取引先の行は売上、スタッフの行は報酬）と、その月の売上・支払・粗利の1行

**お願いすること**: 支払日の日にち（初期値は翌月25日）、使っている銀行（ネットバンキング）の名前と委託者コード、源泉・税込/税抜・freee の税区分の扱い（税理士確認）、freee への取り込みを一緒に試す

2026-10-11 にいただいたご要望（「時間がかかってもいいので進めてほしい」）。決まっていないところは要件 §9 の原則で決めて進め、最後に確認していただく。

| 区切り | 内容 | 終わったら確認できること |
|---|---|---|
| 4-1 日報のフォーマット | 取引先ごとの書式（はじめ / 現場ごと / 1人ごと / おわり、差し込みボタン・プレビュー）。実績確認の「日報」で取引先ごとの文章をコピー / LINE。マイページでも報告のあと本人の分をコピー | 報告を集めて、NICOLY用・ラスタス用・NextWave用の文章を LINE に貼れる |
| 4-2 シートの稼働表の再現と連携 | 書き出しを今のシートと同じ並び（取引先・会場ごとに 単価 / 現場 / 人数、スタッフごとに 単価 / 場所 / シフト。単価の行は空）に。シートの月のタブを CRM から直接読んで取り込む（CSV を落とさなくてよい） | 「CRM 202610」タブが今のタブと同じ並びになる。シートから直接取り込める |
| 4-3 オンライン研修の日程調整 | TimeRex のような予約: 研修の枠を作る → 予約用リンクを LINE で送る → 相手が空いている枠を選ぶ → 一覧・カレンダーに入る。定員・締切・キャンセル | 予約リンクから研修の予約ができる |
| 4-4 AIアシスタント | 右下の「AI」から話しかける。データの質問・使い方の案内・文面の下書き。LINE のスクショを読み取って登録（確認してから）。操作の代行（確認してから） | AI に聞いて答えが返る。スクショから報告を登録できる |

**作りながら決めたこと**
- 日報の件数は、確定していれば確定件数、なければ速報。未報告の人は「（未報告）」と出す
- 日報のフォーマットはオーナーが作る（設定は管理者は不可、のルールどおり）。日報を作る・コピーするのは管理者もできる
- 書式の見本（NICOLY用・ラスタス用・NextWave用）はまだいただいていないので、NICOLY用だけ仮の書式で入れておき、ほかは設定画面で作ってもらう
- シートの再現: 書き出しは今のシートと同じ3行の並びにする。**単価の行は空**（共有するシートに金額を出さない、のルールどおり。管理用シートは「リンクを知っている全員が編集可」のため）。単価は CRM の稼働表のマスにオーナーだけ出す
- 研修の予約: 枠（日時・定員）を先に作り、空いている枠だけを出す形にした（TimeRex の「空き時間から自動で出す」の代わりに、Google カレンダーとつなぐと予定と重なる枠を出さない）。締切は始まる1時間前。予約用リンクは1つ（作る・止める・作り直すはオーナー、枠と予約は管理者も）。予約した人には控えの画面（参加の URL・カレンダーに追加・キャンセル）を出し、リンクを止めても控えは見られる。カレンダーの連携は任意（オーナーがカレンダー ID を入れたときだけ）
- シートとの連携: 管理用シートの月のタブを CRM から直接読んで取り込める（今までの CSV 取り込みと同じ確認画面）。シート → CRM は「取り込むときだけ」、CRM → シートは「CRM 〜」タブへの自動書き出し（同時に両方向に自動で合わせることはしない。食い違ったときにどちらが正しいか決められないため）
