## Phase 1: 現場・アサイン・実績（最優先）

小さく区切って作り、区切りごとに動くものをお見せします（承認は Phase 1 の最後にまとめて）。

| 区切り | 内容 | 終わったら確認できること |
|---|---|---|
| 1-1 基盤 | DB（全テーブル・RLS・トリガー）、ダミーデータ、ログイン（招待・Google・マジックリンク）、画面の骨組み（下部タブ / サイドバー）、PWA、設定（ユーザー・役割・獲得項目・ランク・エリア・テンプレート・締切日） | ログインして空の画面を行き来できる。管理者で金額が取れないテストが通る |
| 1-2 スタッフ・会場・取引先 | 一覧・詳細・登録、NG、稼働履歴メモ、マイページURL（発行・コピー・LINEで送る・再発行）、取引先は最小限（名前・連絡先・担当者） | ダミーのスタッフを検索・編集できる |
| 1-3 現場 | 作成・まとめて作成・複製、一覧（リスト / カレンダー・祝日）、詳細、欠員の表示 | 来週の土日2日分を1分以内で作れる |
| 1-4 アサイン | 候補を探す（並び順・警告）、一括打診、文面の作成と LINEで送る / コピー、状態の手動変更、確定連絡・前日リマインド、キャンセル理由 → 稼働履歴メモ | 3人に打診して LINE が開く |
| 1-5 マイページ | お願い・予定・実績報告・稼働可能日・過去の稼働、レート制限、ホーム画面に追加 | スマホで回答・報告・稼働可能日の提出ができる |
| 1-6 回収・確定・ホーム | 稼働可能日の提出状況と依頼文面・代理入力、実績確認（確定・一括確定・差分理由・履歴）、交通費・経費の承認、ホーム（お金以外）、横断検索 | 欠員・未報告・未回答がホームに出て、片づくと消える |
| 1-7 取り込み・仕上げ | CSV 取り込み（スタッフ・取引先・会場）、変更履歴画面、マニュアル（管理者向け・スタッフ向け）、受け入れテスト（要件 §10 Phase 1）の自動化、本番デプロイ | 実際の名簿を取り込んで使い始められる |

- 金額系のテーブルと RLS はこの段階で作る（名簿の取り込みで基本日当なども入れるため）。お金の画面は Phase 3。
- Phase 1 完了後、**実データで1〜2週間試していただき**、フィードバックを反映してから Phase 2 へ。

**お願いすること**: 1-5 でスマホ（iPhone / Android）での確認、1-7 の前に取り込み用 CSV（個人情報はダミー化して可）

## Phase 2: 営業・追客 ＋ 分析

- 取引先・協力会社の完成版（6段階ステータス、カンバン、担当者、活動履歴、次回アクション必須チェック）、活動の記録（スマホで10秒）
- ホームの「今日やること」
- 過去の稼働・実績の取り込み（平均獲得件数に反映）
- 実績ランキング、会場別・取引先別の分析

## Phase 3: お金

- 単価設定（取引先の標準・現場ごとの上書き）、インセンティブ単価、日当の上書き、調整額
- 請求・支払いの計算（`src/lib/money`、要件 §10 の計算テストケース8件）、源泉徴収
- 月次締め・ロック・ロック解除
- CSV 出力（請求集計・支払明細・freee 取込用・全データ一括）、売上・粗利のダッシュボード、目標
- （任意）全銀フォーマットの振込データ

**お願いすること**: freee の取込サンプル（または最新ヘルプの確認）、源泉・税込/税抜の扱い（税理士確認）、全銀データを作る場合は銀行名
