## Phase 1.5: 稼働表とシート連携 — 完了（2026-10-10 承認）

Phase 1 の公開後に「今のスプレッドシートの運用に近づけたい・連携したい」とご要望をいただき、**Phase 2 より先に**作ることになりました（2026-10-10 決定）。
今の月のシート（202605〜）は、横に日付、上の段に取引先ごとの「単価 / 現場 / 人数」、下の段にスタッフごとの「単価 / 場所 / シフト」が並ぶ1枚の表です。

| 区切り | 内容 | 終わったら確認できること |
|---|---|---|
| 1.5-1 稼働表の画面 | 「現場」に月の稼働表を追加。上の段は取引先×日付（会場・確定/必要人数、欠員は赤）、下の段はスタッフ×日付（確定は緑、打診中は黄、稼働可能日の ⭕️🔺❌）、右端に稼働日数。マスを押して打診・確定・稼働可能日の代理入力。名前の列は固定し、スマホでは表の中だけ横に動かす | 今のシートと同じ見え方で月全体を見渡し、マスから打診・確定できる |
| 1.5-2 月のシートの取り込み | 「データ取り込み」に「月の稼働表（スプレッドシート）」を追加。月のシートを CSV で保存して読み込み、取引先・会場・現場・アサイン・稼働可能日・単価（オーナーのみ）を作る。名前や会場名が合わないものは確認画面で選び直す。5〜10月は過去の稼働、11月以降は予定として入る | 今のシートの11月分を取り込んで、入れ直さずに使い始められる |
| 1.5-3 見るだけリンク | 稼働表をログインなしのリンクで現場リーダー・スタッフに共有。オーナーが発行・再発行・停止できる | スマホでリンクを開くと最新の稼働表が見られる |
| 1.5-4 シートへの自動書き出し | 稼働表を、今と同じ形の**別の**スプレッドシートに10分ごと（とボタンで）自動で書き出す。見るだけ用（シートで直しても CRM には戻らない） | 共有中のシートが自動で最新になる |

**決めたこと**
- 共有（見るだけリンク・書き出すシート）に載せるもの: どこで稼働するか（場所）、シフト（⭕️🔺❌）、ランク、最寄り駅、上の段（取引先・会場ごとの必要人数と確定人数・欠員）
- 共有に**載せないもの**: 単価・売上・人件費・利益などの金額、電話番号（要件「金額はオーナーだけ」）
- シートで直した内容を CRM に戻す双方向の連携はしない（入力場所が2つになり食い違う・変更履歴と権限が守れないため）
- 稼働表の金額の列（売上・人件費・利益）はオーナーだけに、Phase 3 で表示する

**お願いすること**: 1.5-4 の前に Google Cloud の設定（サービスアカウント。手順は setup.md に追記します）、書き出し先のスプレッドシートの作成

## Phase 2: 営業・追客 ＋ 分析 — いまここ

| 区切り | 内容 | 終わったら確認できること |
|---|---|---|
| 2-1 営業の完成版 | 一覧のリスト ⇔ カンバン、並び（今日以前 → 未設定 → 先の予定）、絞り込み（ステータス・次回アクション・担当者・優先度）、会社の画面に活動履歴 | 次回アクション未設定の会社が一覧で分かる |
| 2-2 活動の記録 | 画面下からのパネル（種類 → 結果 →（メモ）→ 次回アクション日を押すと記録）、元に戻す、ホームの「今日やること（営業）」、右下の ＋ に「活動を記録」 | 架電のあと、スマホで10秒程度で記録と次回アクションの設定ができる。今日以前の会社がホームに出る |
| 2-3 過去の実績の取り込み | 過去の獲得件数を「記録のみ」の稼働に付けて取り込み、平均獲得件数に反映 | 過去の実績が候補一覧の平均獲得件数に出る（**記録をいただいてから**作ります） |
| 2-4 実績の分析 | スタッフ別・会場別・取引先別の獲得件数・1稼働あたり・稼働（金額なし）、期間・確定 / 速報の切り替え。ホームの実績トップから進める | 会場別・取引先別に比べられる |

**決めたこと**
- 次回アクション日の候補（明日 / 3日後 / 1週間後）を押した時点で記録する（タップを減らすため。画面一覧 §4）。種類の初期値は「架電」
- 「次にやること」は結果に合わせた候補を最初から入れる（直せる）。日付だけ選んで空のときは「連絡する」
- ステータスは、進んだことがはっきりしているときだけ1段進める候補を出す（未接触 → 接触済み、アポ獲得 → 商談設定、商談の記録 → 商談済み）。取引中・見送りは自動では変えない
- 記録の取り消しは、記録した本人が15分以内だけ（それ以外は履歴として残す）
- ホームの「今月の獲得件数」と実績の分析は同じ数え方にそろえた（速報ベースで速報がない＝管理者が直接確定したものは、確定の件数を使う）

**お願いすること**: 過去の獲得件数の記録（2-3 で使います）
