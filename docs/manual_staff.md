# マイページの使い方（スタッフ向け・LINE でそのまま送れる文面）

---

【NICOLY マイページの使い方】

お疲れさまです！NICOLYです。
あなた専用のマイページURLを送ります。ログインは不要で、ずっと同じURLで使えます。
ホーム画面に追加しておくと便利です（iPhone は共有ボタン →「ホーム画面に追加」）。

■ お願い
現場の打診が来たら「参加できる」「できない」を押してください。
空きがあればそのまま確定です。

■ 予定
確定した現場の日時・集合時刻と場所・住所（地図）・持ち物が見られます。
稼働日の当日は「現場に着いたら（稼働開始の報告）」が出る取引先があります（NextWave など）。現場に着いたら「LINEで送る」か「コピー」で送ってください。2人以上の現場は、代表の1人が送ってください（全員の名前が入っています）。

■ 報告
稼働した日の夜に、獲得件数（＋ / − で入力）・一言コメントを送ってください（日当は交通費込みなので、交通費の申請はありません。遠い現場は管理者に連絡してください）。
稼働日から7日後までは修正できます。
送ったあと、下の「LINE用にコピー（日報）」から、決まった書式の日報をコピーして LINE に貼れます。
2人以上の現場（NextWave など）は、全員分をまとめた日報が出ます。代表の1人が送ってください（まだ報告していない人の名前も出ます）。
項目が多いときは「項目をさがす」に名前の一部を入れると見つかります。
LINE に書いた報告（NICOLY フォーマットや、キヘン・光 などいつもの書き方）は、報告の画面の上の「LINE に書いた報告から入れる」に貼ると、あなたの分の件数を読み取ります。「この件数を報告に入れる」を押し、件数を確かめてから「送信する」を押してください。
- 「新規1(山田)」のように名前が付いた行は、その人の分として読みます（ほかの人の行は入りません）
- 「後日」の下に書いた分は、後日の獲得として入ります
- 項目の下に書いた乗り換え元・端末などは、件数には入れず、一言コメントに入ります
- 取引先の書式があるときは、取引先の名前と形に直した文も出るので、「コピー」で LINE に貼れます

■ 稼働可能日
カレンダーの日付をタップすると ○ → △ → × と変わります。
毎月10日までに、翌月分を「提出する」を押して出してください。10日のあとに入れそうな日が分かったら、管理者に連絡してください。

■ 過去
これまでの稼働と、自分の獲得件数が見られます。

■ LINE でお知らせを受け取る（おすすめ）
「お願い」のいちばん下の「LINE とつなぐ」を押して、
① 公式アカウントを友だち追加 → ② 「コードを送る」を押して LINE で送信
これだけで、現場が確定したときと前日に、LINE にお知らせが届きます。

URLは他の人に教えないでください。分からないことは管理者まで！
