# Phase 0 の確認事項

要件 §13「仮置きの前提」と、共有いただいたスプレッドシート（【NICOLY】モバイルイベント 甲斐軍団（管理用））の構成を見て出てきた確認事項です。
「推奨」は、こちらで進めるならこうする、という案です。回答はこのファイルの「回答」欄に記録します。

> スプレッドシートは**列や書き方の構成だけ**を確認しました。氏名・電話番号・口座などの中身はリポジトリに一切保存していません。

## スプレッドシートから分かったこと（要約）

| 項目 | 現状 | 設計への影響 |
