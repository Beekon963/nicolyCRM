**2026-10-06 に回答をいただきました。** 要件定義（`docs/requirements.md`）と食い違う点は、**このファイルの決定を優先**します。

## 3. §13 の前提

| # | 前提 | 回答 |
|---|---|---|
| 13-1 | 役割は「クローザー / キャッチャー / ディレクター」の3つで始める（設定で追加できる） | **このまま** |
| 13-2 | → 上の 2-1 | **両方分ける** |

| 13-4 | 管理者は交通費・経費の申請額を見て承認できる（日当・単価・支払額は見えない） | **このまま** |

| 13-6 | 日当・インセンティブは税込金額として扱う | **このまま** |
| 13-7 | 源泉の対象額に交通費を含め、税込で計算する（設定で変更できる） | **このまま**（税理士に確認後、必要なら設定で変更） |
| 13-8 | 稼働可能日の提出締切は毎月20日（翌月分） | **このまま** |

## 5. 補足

- 現在のスプレッドシートには口座番号・電話番号がそのまま入っており、所有者は UPDRAFT のアカウントになっています。CRM へ移行したら、口座などの列の削除や共有範囲の見直しをおすすめします（CRM では口座はオーナーしか見られません）。
